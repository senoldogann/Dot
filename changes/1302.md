- A command line handed to a program through its own option is judged like the same line under `bash -c`:
  `sqlite3`'s `.shell`/`.system`, `vim`'s `-c '!cmd'`/`+!cmd`, `emacs --eval '(shell-command ...)'` and `tar`'s
  `--use-compress-program`/`-I`, `--to-command` and `--checkpoint-action=exec=` now ask when the line is harmful.
  Plain `sqlite3` queries, `vim` and `emacs` without those options and ordinary `tar` run as before (item 1302).
