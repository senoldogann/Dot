- The tools of a run are files for its code (item 1502): `from dot_tools.servers.dot import read_file` and `from
  dot_tools.servers.<server> import <tool>`, a function for each tool made from its schema (keyword-only, typed, the description
  as its docstring), written once on the run's first `code_run` and found with `dot_tools.search_tools` and
  `dot_tools.list_servers`, so that no definition of a tool the code can call goes into a prompt ([Code mode](docs/code-mode.md)).
