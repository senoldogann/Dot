- The commands a run starts are no longer given more of the variables that carry a secret: personal access tokens
  (`GH_PAT`), passwords under other names (`MYSQL_PWD`, `DB_PASS`), DSNs, cookies, sessions, webhooks and addresses with a
  password in them (`DATABASE_URL`, `HTTPS_PROXY`) stay out, while ordinary variables (`PATH`, `PWD`,
  `XDG_SESSION_TYPE`, `HOMEBREW_*`, the Git author) and `SSH_AUTH_SOCK` are given (item 1293).
