- A task run or a campaign can carry proof checks: commands with a time limit (a test run, a `curl`, a `test -s`) that
  must exit 0 before Dot marks it done. Set them with `dotx run --proof CMD`, `proof` of `POST /api/runs`, or let the
  run add one with `add_proof`; a failing check sends the run back with its output, one that cannot run ends the run
  failed, and a campaign's claim is refused while its check fails (item 1853).
