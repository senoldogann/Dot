- Safety: once a run has read untrusted content (a web page, an MCP result, mail), installing software (`brew install`,
  `pip install`, `npm install -g`, `cargo install`, `uv tool install`) or running opaque code — a script the line
  downloaded, or a blob it decoded and ran (`base64 -d x | sh`) — asks first in the default `aggressive` preset too, as
  sending data out does. A project's own install (`npm install`, `uv sync`) goes ahead as before (item 523).
