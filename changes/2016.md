- A run nobody started keeps the sandbox in every mode: the processes of a run of a schedule, a watcher, a hook, Dot's
  own initiative, a mail's reply handed on, and of what goes on from them (their helpers, a resume), start in the macOS
  sandbox in yolo and free mode too, whatever `[shell] sandbox` and Settings › Rules say, and so do a schedule's and a
  watcher's checks. It seals Dot's own files, `[policy] sealed_paths`, what Dot runs, launchd hand-offs and the
  clipboard, and nothing else of the task's reach; it asks nothing new. A run you start runs as before. `[shell]
  sandbox_unattended = false` turns it off (item 2016, [Safety](docs/safety.md), [Freedom](docs/freedom.md)).
