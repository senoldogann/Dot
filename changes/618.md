- A run you start from iMessage tells what it does while it works (item 618). iMessage cannot edit a message it sent,
  so it is a few messages and not a stream: after 15 seconds of work one message, then at most one every 30 seconds
  and six in all, each of what happened since the one before, the newest last: the commands it ran (`$ ` and their
  first 60 characters), the tools it used in the page's words (*used the desktop*, *read a page: example.com*, *wrote
  notes.txt*) and the first sentence of its newest thought (`💭 `) when the model thinks. A run that ends sooner sends
  only its answer. Never a tool's output; a page by its host alone; masked of the secrets Dot holds like an answer.
  Settings › Channels › iMessage has a **Progress messages** switch (`[channels] progress`, `"steps"` by default or
  `"off"`), live.
