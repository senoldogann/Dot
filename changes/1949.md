- Custom providers (item 1949): any service that speaks OpenAI's Chat Completions or Responses API or Anthropic's
  Messages API can be added as a provider of its own, in Settings › AI services › Add provider or as
  `[providers.custom.<name>]` in `config.toml`, and its models (`<name>:<model>`) used anywhere a model is chosen.
  Fill from docs proposes the fields from the provider's documentation page, Test makes one small call when you press
  it, and the key is kept like every other key. The phone lists them in Settings › Models.
