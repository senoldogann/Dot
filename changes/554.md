- Browser: a tab a page opened, or one a page sent itself to later on a timer, is checked against the address rules
  before anything is read from it or done in it, in Dot's own Chrome and in yours: a popup that lands on Dot's own
  interface or a blocked host is reset to a blank page and the page that opened it is told, and so is a frame of a page.
  The hops of a popup's first redirect are still sent before Dot can ask, and what they answer is never read (item 554).
- Taking a run over after it ran a script in the page (`browser_eval`) closes the chat's other tabs and opens the page
  again, so that a listener the script left cannot copy a password you type; the run's next view says so (item 554).
- Web tools: a body is inflated a piece at a time, gzip or deflate once, so a few hundred bytes of nested gzip are not
  gigabytes in memory; a page read in the browser after a plain request was turned away is not given back when it was
  served from a private or local address; a page the crawl cannot decode or open is left out without losing the pages
  read, and a crawl no longer reads past `max_depth`; what pages and links write in the crawl's index, a missing page's
  links and `web_extract`'s JSON stays in a `<web_content>` fence; `web_extract` ends at its own time with what it has;
  an Anthropic answer without a search moves on to the next engine, Ollama's limit benches it, and a larger
  `max_results` is a new search (item 554).
- Settings: a card's expiry month and year in dropdowns are card fields, refused outside `yolo` and covered in a
  screenshot; a blocked or allowed host written in Unicode, with a trailing dot or as a number now names the host;
  Incognito is emptied also when its Chrome was quit; switching the browser closes the session a campaign had made for
  that mode; `dotx browser import-chrome` and Dot's Chrome no longer run on the profile at once; a recording keeps at
  most 400 steps (item 554).
