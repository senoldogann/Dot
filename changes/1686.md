- The phone's sync contract (item 1686): `GET /api/threads/{id}/view` gives a chat's state at a revision that every
  change of it moves (SQLite triggers, whichever process writes), `GET /api/threads/view` the chats with theirs, and
  `GET /api/threads/{id}/stream` one stream for a chat's runs, the runs that start later in it and their helpers, from
  the client's own cursor of each run, with `thread_changed` and `synchronized`; `GET /api/threads/stream` is the list's.
  Both write a keepalive every 5 s. The schema is `docs/schemas/thread-sync.schema.json`
  ([Dot on the phone](docs/phone.md)).
- A helper's report to its chat's run says so in its `steer` event (`of_dot`, `source: "helper_report"`,
  `helper_run_id`), for a client to draw it as Dot's row (item 1686).
