- iMessage works when this Mac's Messages and your iPhone use different Apple IDs: a message received from the number or
  address you paired, in the conversation named for it, is a command, and Dot answers in that conversation. It is judged
  like one sent from the Mac, so one you write while a run sends something may be told and need sending again. A
  message that Messages keeps as a sent row and a received row, with the same words within 10 seconds in one chat, runs
  once. Pair the number or address your iPhone writes from, and only your own: pairing someone else's gives them Dot,
  and the tab says beside each paired one *Messages from this address run as you* (item 595).
- Settings › Channels says what Dot sees of Messages' database: the newest message and when Dot first saw it, how far it
  has read, when it last looked, the size and time of the last change of `chat.db` and `chat.db-wal`, the last row it
  took as a command and the last error. It warns when Messages has written its log for two minutes while nothing Dot can
  read changed, and **Check now** looks at once (a poll, with the channel on; only a look, with it off).
