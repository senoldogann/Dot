- Dot on the iPhone as an app (`ios/`, installed from Xcode): the same web UI in a native shell, with a run of yours
  on the lock screen and in the Dynamic Island as a Live Activity (working, waiting for you, done), and Dot's alerts
  through APNs. Set `[apns]` with your APNs key to switch it on; alerts carry only Dot's fixed titles (item 997).
