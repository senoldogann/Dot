- The shell guard reads more of zsh's ways as zsh does, so the presets that ask now ask about them: `+=` added to a
  variable, a quote right after a variable's name, a comment or a here-document inside `$(...)`, `cd OLD NEW`,
  `chdir`, `CDPATH` and `cdpath`, a `~` under the `HOME` the line set, braces in the command's place, zsh's `-` before
  a command, an `alias`'s line and an element of zsh's `aliases` or `functions` table, a line given to `npx -c` or to a
  program it does not know with `-c` or `-e`, and a version in a shell's or an interpreter's name (`perl5.34`). A C
  shell's line (`csh`, `tcsh`) is read as one it cannot read. A test checks the guard against a real zsh. Yolo and free
  mode ask nothing new (item 1250).
