- Dot speaks Google: a key from Google AI Studio (`dotx auth set GOOGLE_API_KEY`) brings the Gemini models — free within
  their daily limits — as `google:<model>` in the model picker and the AI services page, and a Google Antigravity
  account brings its Gemini models as `antigravity:<model>` (item 1228).
- A tool schema whose bound sits in the field's own metadata no longer reaches a provider as `gt`: it is written as
  `minimum`/`maximum`, so a Gemini model, which refused the whole request over it, takes Dot's tools (item 1228).
