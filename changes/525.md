- Safety: a yolo run that read outside content (a page, a mail, a tool's answer) has the review model check, without
  asking you, a step an instruction planted there would be after: a message, a post, an upload, a payment, a
  credential, a read of your secrets, an install, a note it saves. A step it finds you did not ask for is refused,
  and the run goes on with the rest. `[policy] yolo_taint_check = false` turns it off (item 525).
- Safety: in every mode, yolo too, a run that read outside content has a step refused whose words would send a secret
  Dot holds, or text in the form of a key, out of the Mac: a request, a message, a page's field, an MCP tool or a
  command line. Its record masks the secret (item 525).
