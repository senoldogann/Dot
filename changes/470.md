- Runs: the page of a run you hold can be used from the screen that shows it, a phone's too, through the API
  (`POST /api/runs/{id}/takeover/screen` and `/input`): your taps, scrolls and keys reach the page while the run waits,
  even in a browser without a window, and nothing of what you type is kept; Settings › Browser switches it
  (`[browser] remote_input`, on by default). The run page's controls for it follow (item 470).
