- A chat is the agent's own (item 1260): the chat a message to an agent reaches is bound to it, so every run started in
  it is the agent's — the pages, the chat list, the phone, a queue that drains, a reaction's follow-up, a background
  command that ends — with the agent's model, reasoning level and approvals; its home chat is the newest chat that is
  its own, a run of Dot's in it no longer takes it away, a chat is never taken from a team or another agent, and
  forgetting an agent leaves its chats as plain chats.
