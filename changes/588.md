- Safety, from the harness audit of 2026-10-23 (item 588): the nightly self-improvement no longer undoes what you do
  while it runs. A version you adopt while a step plays stays in use (it used to become "tried" and the page said
  Built-in), a version you set aside stays set aside, and with `adopt = "auto"` the step puts its own version in use
  only over the one that was in use when it began, never over one you chose since; a step that failed after its trials
  adopts nothing. A version the step composed of versions written from a run that read a page is marked as such, and
  adopting any such version asks first: `dotx harness adopt` warns and asks (`--yes` to skip), the page's **Use**
  asks, and its row wears a *From outside content* pill. The test tasks stay out of the models' reach: the composer
  and the experience writer of the loop are told how many tasks a version did better and worse on and never which, and
  a lesson of theirs that names one is asked for again; twelve nights in a row from read pages no longer hide the
  lessons before them. A run now says which version of the harness it took (in its record and the API), and `dotx
  stats` counts the finished runs per version.
  The review of item 588 made three corrections (round 1): a version composed of versions written from a page warns
  even when it was composed before Dot noted that, and a version whose notes cannot be read is never taken for clean;
  the warning, the question of the page and the pill say what the run read (a page in the browser, a web address, the
  screen, a tool server's answer) and no longer say "a download"; and a lesson of the loop that says what a version did
  with `bump version` or `report failing tests` no longer fails a step for naming a test task: only a task's own id
  does.
