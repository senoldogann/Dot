- web-research 1.4.6. Every browser it starts, Chrome or Camoufox, for a page or for a search, is held to its address
  guard: it reaches neither this Mac nor the private networks. A read that blocks the browser ends instead of hanging,
  and a map or a crawl that redirects to another site reads only the page it leads to. While you have a list of sites
  set, it fetches no Camoufox browser by itself. An Intel Mac installs it without Xcode's tools, with no Camoufox.
  It starts in its own data folder rather than the workspace, and `[[mcp]]` takes a `cwd` (item 637).
