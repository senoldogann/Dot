- `code_run` (item 1501): the model writes Python that calls its tools as functions in a sandbox and prints only what it needs
  (`[code]` in `config.toml`, [Code mode](docs/code-mode.md)). It is a shell line to every approval mode and to your rules,
  each tool call its code makes goes through the same gate, approvals, masking and events as a call of the model's (the
  events say `"via": "code"`), a refused call raises in the code with the gate's words, and where the sandbox cannot start
  Python nothing runs.
