- web-research comes with Dot (item 583): Dot's package depends on `dotagent-web-research` 1.2.0, the MCP server that
  searches the web and reads pages, and the daemon starts it as the MCP server `web-research`, with the servers of
  `[[mcp]]`, in every install, on by default. Its tools (`mcp__web-research__web_search`, `web_scrape`, `web_map`,
  `web_extract` and a crawl that runs in the background) are offered and judged like any MCP server's: the six that only
  read run as reads, `web_crawl_start` and `web_crawl_cancel` by their flags, and what they return is untrusted content.
  It sends the queries to DuckDuckGo and Yahoo, and to Google when those refuse, and requests the pages a run asks for
  (what leaves the Mac says it); its crawl jobs are kept in `web-research/` of Dot's home, which a run's commands cannot
  change, and it reads no `.env` into its environment (`PYTHON_DOTENV_DISABLED=1`). Its calls are judged by the rules of
  Dot's own `web_search`, `web_fetch` and `web_crawl`, in the same functions: a key in a search (its query or its sites)
  or in an address, or a long address, is flagged as it is there (the policy refuses it), your `[browser] allowed_hosts`
  and `blocked_hosts` bind the addresses its tools read, and a search that reads the pages it found is refused while you
  have set a list; a redirect, the links of a crawl, the search engines and the Internet Archive are not checked, and a
  crawl goes on after its run until it ends, up to its page limit, or the daemon stops. Customize › Connectors lists it
  with a **Built in** chip and a switch (and **Try again** when it was left out), `dotx mcp list` marks it `built-in`,
  and `dotx doctor` has a row for it. `[builtin_mcp] web_research = false` leaves it out (the table is not `[mcp]`,
  which TOML cannot have beside the `[[mcp]]` tables); a `[[mcp]]` table, a plugin's server or an added server named
  `web-research` replaces it, and an eval run leaves it out. The server starts with `-P`, so that no file of the
  workspace, where a run's commands write, can be imported by it.
