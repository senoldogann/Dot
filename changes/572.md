- Channels: a message you send to yourself in Messages on your iPhone starts a run in a chat of its own, "iMessage", as
  one typed in the web UI does, and its answer comes back in that conversation marked `◆`, as plain text cut to about
  2,000 characters with a link to the chat; a run that waits for you sends one line, and approvals are answered in Dot,
  never in a message. Only your own one-to-one conversation over iMessage is ever read, `/stop` stops the run at work,
  and Settings › Channels (beside Phone) switches it, pairs your number or Apple ID address with a code you type back,
  and says what macOS has not granted (Full Disk Access, Automation for Messages) with the step that sets it right (item
  572). A message a run of Dot may have written into that conversation (a step that sends, of any run, recorded as
  sending in the minutes around the row's date; a message Messages sends later) is told and never run as yours, in
  `auto` and `yolo` too, and a draft to a number or address you paired is refused: pair only your own number or Apple ID
  address. Only words are read: a sticker, an app's message or a payment is never a command; a link that Dot wrote,
  which Messages may split off the end of a message into a row of its own (a link preview), is never read back as
  yours; and a link of yours that Messages splits off your words is joined to them, if it comes less than 3 seconds
  after, as one command.
