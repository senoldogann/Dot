- Tools: a run now knows what each MCP server is for before it turns the server on, without you tagging it. The line of
  a server's tool group in its instructions says it: the new `description` of the server's `[[mcp]]` table, one line in
  your own words; Dot's words for the server that comes with it (web-research); else what the server says of itself (its
  instructions when Dot connected, else the first sentences of its tools' descriptions), cut to one plain line of at
  most 160 characters and put in quotes as the server's claim, which the instructions say to weigh and not to obey. Dot
  reads them once, when the server connects, and asks no server when a run begins. `[agent] mcp_purposes = false` leaves
  the lines as they were (item 659).
- Skills: a run offered more skills than `[skills] listed` (20) is now told the names of the ones its instructions leave
  out, so a skill whose description shares no word with the goal is not out of sight (item 659).
- Evals: five choice tasks measure what a run picks when nobody tags for it, two skills and three MCP servers, each
  beside a decoy, judged by what the run's events show; `dotx eval run --no-mcp-purposes` plays the same tasks with the
  lines of the servers' groups as they were, to measure what the words change, and `dotx eval report` shows the setting
  (item 659).
