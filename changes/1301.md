- A write by a file tool (`write_file`, `edit_file`, OpenCode, the pipeline) to a git directory's `config`,
  `config.worktree` or a file under `hooks` (also a submodule's, a bare repository's, and a path with a glob in the
  `.git` part) is a change of a file git runs as code: it asks you in every mode but yolo. A line handed to git or a
  path it is told to write (`git diff --output`, `git archive -o`, `git format-patch -o`, `git bundle create`,
  `git rebase --exec`, `git bisect run`, `git submodule foreach`, `git filter-branch --tree-filter`, `git grep -O`,
  `git difftool -x`, `--upload-pack`) is judged as the same line under `bash -c` and as a redirect to that path
  (item 1301). Not covered: a shell line that writes `.git/config` or `.git/hooks/*` by a redirect or a copy is judged as
  any workspace write; closing that needs the sandbox to deny those writes to commands that are not git, which is for
  you to decide.
