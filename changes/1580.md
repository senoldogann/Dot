- A Claude Code program that ends before its result (killed from outside, crashed or exited by itself) now says how: the
  run's error and the log line `claude_code_program_cut` carry its exit code, the signal's name (a program that ends
  `128 + n`, as Claude Code does on SIGTERM, is read as that signal too), the last 2 KB of its error stream, whether it had
  said what the model has, the steps it took and the seconds since its last line; and `claude_code_programs_ended_together`
  is logged once, with the run ids and signals, when two or more programs of the daemon are cut inside one second without
  Dot ending them (item 1580).
