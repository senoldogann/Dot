- Models: an Ollama model can be given a context size up to three quarters of its own window in Settings › Models.
  That covers a model of this Mac and a cloud model whose own window is larger than the one Dot asks for. Dot then asks Ollama for the window that size needs: a 9B model of 256K given 96K is asked for 128K. Before,
  every local model was held to `num_ctx` (64K) whatever Ollama's own settings said, a budget of 48K, too small for
  the prompt and tools, so agents did not start on local models (item 520).
