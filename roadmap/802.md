### 802. A delegated report is a claim until it says what it verified

**Status: done (2026-10-28).** The video's trust curve puts verification above everything else, and a subagent's report
is the most tempting thing to trust. A `delegate` result ended as done and the parent closed a plan step on the report
alone; nothing asked the child what it had run or seen.

- **The tool asks for it.** The `goal` field and the tool's description now ask the parent to end the child's
  instruction with a `Verification:` section: the command or check and the answer.
- **The result says when it is missing.** `render_outcome` looks for a `Verification` heading at the start of a line
  (plain or Markdown) and appends: "No Verification section was reported; treat the report as a claim and check the
  work before you rely on it." A report that has one is unchanged.
- **No task is refused.** A research report may have no command to run; the warning is honest about the claim rather
  than failing a useful delegation. The parent still decides.
- **Measured.** `uv run pytest tests/unit/test_delegate.py` — 5 passed, including the warning, the clean report and
  the two description checks; `ruff` and `mypy` clean. `docs/agents-and-campaigns.md` says the same.
