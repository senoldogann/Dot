### 1050. A run with two open questions stays blocked until both are answered

**Status: done (2026-11-08).** Part of the owner's ask to make the implicit state machines explicit (item 1045).

The read-only calls of a step run side by side (`agent/executor.py`), and two of them may each ask (a read of a
protected path). Each question set the run `blocked`, and the first one answered set it `running`, while the other
still waited: the pages showed the run at work with the owner's answer still owed. A question answered now moves the run
back only from `blocked` and only when none of its questions is still pending (`Store.unblock_run`).
