### 624. A picture in the file panel opens at full size, and a source file reads as code

**Status: done (2026-10-24).** Work found in progress in the owner's checkout (`filepanel.js`, `run.css`, `ui.js`,
`docs/runs.md` and `tests/smoke/test_file_panel.py`, uncommitted): it kept `~/Desktop/Dot` from taking the merged items
611, 612, 615 and 620. The owner: "finish that work too, then whatever else needs doing". It was saved as a patch
before anything was touched, applied on `main` with no conflict, and finished here.

**As built.**

- **A picture.**
  - It is drawn whole in a frame that fits it, in the panel and in the dialog of a page without the panel, rather than
    at the top of a tall sheet.
  - It is a button that shows it at full size over the page (the viewer of a run's screenshots, `showImage`).
  - A picture that could not be loaded is no button.
  - Escape closes the picture before the panel it was opened from (`ui.js`: the viewer takes the key first).
- **A source file** (Python, JavaScript, TypeScript, shell, Rust, Go, Swift, SQL, YAML and the others of
  `CODE_FILE`, by its extension) reads as code:
  - its lines numbered;
  - its words coloured by their kind (keywords, strings, numbers, comments) by a small reader of tokens that writes
    text nodes alone, so nothing of the file is drawn as markup;
  - its language and its path over it.
  - The rest of the panel holds as for any text: a file cut at the preview's size says so, and **Copy the text** takes
    it.
- **The docs.** `docs/runs.md` (the panel's kinds of file).

**Tests.** `tests/smoke/test_file_panel.py`:
- a picture fits its frame in a dialog;
- a press shows it at full size, and Escape closes it first;
- a Python file the answer names opens as code (`python`, its path, lines 1 to 4, a keyword, a comment, a string),
  with Copy the text.
