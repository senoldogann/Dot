### 664. Dot reacts to your message

**Status: done (2026-10-26).** The owner showed another agent app that puts 👍 on the owner's "Send it. Run this every
week." and answers "Done.", and asked whether Dot should react too. It should, in a narrow way: a reaction says
"understood, done" where words would add nothing, and the badge says it at the message it answers.

**The change.**
- `tools/meta.py`: `react`, a meta tool of the core group, with 👍 (understood, done or being done) and 👀 (looking
  into it, it takes a while) and nothing else. It emits `dot_reaction` on the run; a second reaction in the run is
  refused, and two calls of one step run one after the other so the second sees the first. A run another run handed
  its work to, which was sent no message of the owner's, is not offered it (`agent/loop.py`), and the tool refuses one
  all the same; nor is a run no message of theirs started (a schedule's firing, a watcher's look, the reflection, a
  resumed run, a background note), whose 👍 would stand on words they never wrote (`tests/smoke/test_taught_repeat.py`
  checks a firing). An agent's own run keeps it beside `finish`, `ask_user` and
  `use_tools` (`AGENT_CORE_TOOLS`). Its definition is about 100 tokens: the prompt of a model with a small window has
  little room left (`tests/smoke/test_scaffold.py`).
- The conversation draws it on the owner's latest message when it comes (`messages.js` `showDotReaction`): a round
  badge on the bubble's lower left corner, away from the foot at the right, that pops in once; `timeline.js` for the
  run's page, `history.js` for an earlier turn. The call is no step (`QUIET_TOOLS`, as a finish is), nor a line of the
  status line or of a channel's progress messages.
- `docs/runs.md` says so.

**Checked.**
- `tests/unit/test_dot_reaction.py`: one reaction a run, none from a delegated run, only 👍 and 👀.
- `tests/smoke/test_dot_reaction_page.py`: a scripted run that reacts and answers "Done." shows the 👍 on the corner of
  the message, wide and at a phone's width, with no step; the follow-up's page keeps it on the earlier turn and shows
  no other.
- `test_tool_groups.py` and `test_agents.py` name the new tool; the core group stays under 0.46 of the definitions.
- `tests/smoke/test_delegate_agent_tools.py`: an agent's run is offered it, its helper is not.
