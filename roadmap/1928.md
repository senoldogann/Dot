### 1928. Route new runs and helpers by task kind

**Status: done (2026-11-26).** Preserve the existing scoped security choice. Classify the opening
request, or the delegated brief, with a deterministic rule. Normalize Unicode and case, then match code changes
(an action with a repository or code object), writing (a composition or editing action with a text deliverable),
deep work (an explicit investigation, analysis or design request), then quick work (a lookup of at most 24 words
without multiple steps). Match English and Turkish cues at the opening; leave ambiguous requests on their existing
default. A task may intentionally match nothing. A model call for classification would add latency to every ambiguous
request, with no labeled sample to show that it would be more reliable. Existing explicit model choices take precedence.

copied out. Security uses the existing scoped rule. The latest plan for each run, where present, was classified
