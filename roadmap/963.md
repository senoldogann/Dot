### 963. A run of Dot's own initiative may send a note to a run of the owner's chat

**Status: done (2026-11-03).** **Asked** by the owner on 2026-11-03, with a screenshot of a note refused: in a chat Dot
opened on its own initiative the owner asked it to check the work of another chat of theirs, and `send_to_chat` was
refused, since such a chat's runs ask before a message, a post or a release in every mode (item 850) and the owner's
yolo chat does not ask a release. Asked which way, the owner chose to let it through to the owner's own chats, once a
release in a run that read outside content is checked (item 962, which its pre-push review found missing: a deploy ran
there unchecked).

**What holds.** A run of a chat the owner opened (an agent's chat among them) asks a payment, a message, a mail and a
post itself, or has the review model judge them (item 860), and the note marks it as content third parties can author
(item 957), so a release there (a step the shell guard flags `release`) is checked by the review model as after a page
(item 962), and its refusal stands. A run of a schedule's or a watcher's chat, which in yolo asks nothing, is still
refused, as is a run whose approval mode asks less than the sender's, and a yolo run of the owner's chat while `[policy]
yolo_taint_check` is off, which nothing would check. The independent security review found a chain: the owner's chat
run, marked by the initiative's note, sent a note on to a schedule's run, which the initiative could not reach itself.
So a run marked untrusted sends no note at all: a note marks its reader, and no chain of notes carries a page's words,
or a note's, past the rules each run keeps. A `preapproved` rule of the owner's lets a step through in a run a note
marked as it does after a page (documented).

**Built.** `RunManager.note_chat`: a sender marked untrusted is refused; the initiative rule refuses a reader that is
neither a run of Dot's own initiative nor of a chat the owner opened (`Gate.owners_chat`), and one of the owner's in
yolo while the taint check is off.

**Checked.** `tests/smoke/test_chat_notes.py`: a run of Dot's own initiative notes a yolo run of the owner's chat (the
note marks it) and is refused one of a schedule's; a marked run of the owner's chat is refused a note on to the
schedule's; with the taint check off, the initiative is refused the owner's yolo run too.
