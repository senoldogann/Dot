### 896. Free agents offer help to the agents at work

**Status: done (2026-11-01).** **Asked** by the owner (2026-11-01): "olayın dışındaki ajanlar projede çalışan ajanlara
yardım teklif edebilsinler, eğer mantıklı ise bu feature'ı da ekle, test et, tamamla".

How it was weighed: an agent that is free has no run, so it cannot think of offering on its own without a run of its
own, a model call for every free agent each time one starts working. Matching by meaning was measured first with the
owner's embedder (bge-m3): five goals (four Turkish) against seven template roles scored 0.44 to 0.57 for every role
alike (an invoice check came out nearest to Expense Manager, 0.57, but a price research nearest to it too, 0.55), so no
line could be drawn. One fast-model question per run at work, asked only while the office is open and kept, matches
them instead; the owner decides.

- `agent/offers.py`: `at_work_and_free` (Dot's newest run and each agent's that is queued or running and waits for
  nobody; the agents neither at work, waiting nor paused), `ask_helpers` (the goal in a fence that cannot be closed, the
  free agents a line each, one tool call `help_offers`: at most two names of the list, each with a part of 100
  characters, masked), `OfferBook` (one task per run however many pages ask, the newest 64 kept; a failure offers
  nothing). The call's purpose is `offer`.
- `GET /api/agents/offers` (`routes_agents.py`): the offers of the six newest runs at work, a helper that has started
  working since left out; nobody is asked when no run works or no agent is free.
- `office.js`: the offers are read after the agents; a helper walks to the one at work once per run ("Offers to help
  …"), and both panels list the offer with **Let it help**, then **Told**. `POST /api/agents/offers/help` tells the run
  at work `help_note`: the helper's name and role from its record and `message_agent`, never the part the model wrote,
  as Dot's note (`manager.tell`, a `note`: no vouching, no instruction to the reviewer). A steer, which the first
  version sent, is the owner's words and cleared the run's mark of content others can write (the pre-push review).
- `docs/agents-and-campaigns.md` says so.

**Checked.** `tests/unit/test_help_offers.py` (at work and free told apart, a paused agent and a waiting run left out;
the fence; only free agents, each once, at most two, no secret; one call for two pages; a model that fails or does not
call the tool offers nothing); `tests/smoke/test_office.py` (the daemon answers `[]` with no run at work; the helper's
panel and the working one's list the offer, Let it help posts the helper and the run alone, then Told; the endpoint is
404 for an agent that is not); `test_let_it_help_is_dots_note_which_clears_no_mark` (the route calls `tell` with a
`note`, never `steer`).
