### 788. The shell guard reads the Mac's system tools by their reads

**Status: done (2026-10-28).** **Asked** by the owner, from the review of every module. The shell guard took a line of
`diskutil` for a query unless it held one of six destructive words, a line of `defaults` for a read unless its first
argument was a write verb, and a line of `networksetup`, `systemsetup`, `pmset`, `scutil`, `spctl` or `csrutil` for a
read when any argument began like a read. So these went through as safe, in every preset, `cautious` included:
`diskutil apfs deleteContainer disk3` (a whole APFS container), `diskutil randomDisk 1 disk3`, `defaults -currentHost
write …` and `defaults -host localhost write …`, `networksetup -setwebproxy Wi-Fi status.example.com 80` (the host
began with "status") and `systemsetup -setremotelogin on -getremotelogin`; `tmutil disable` and `tmutil delete` were a
plain command (low).

**The approach.** What must hold here is not the kernel's: the sandbox of the modes that ask keeps a command from files
and from some services, not from the disk and preference services these tools speak to, so the guard is what asks.
Chasing spellings would close one and open the next (items 531 and 534); the guard is turned around instead. For each of
these tools it lists the reads, never the changes: a line is a query only when its verb (or each option, for the tools
that take their verb as an option) is a listed read, and anything else, a verb Apple adds tomorrow included, is a change
and asks (every change of `diskutil`, and `tmutil`'s deletions, flagged destructive too). A read the lists do not name asks once more than it
must; that is the cost, and it is said here. What the guard does not read is as before (docs/safety.md): a name a line
builds as it runs, a script in a file.

**The exact shapes** (the review and the independent security review of the first push): a read option beside a
verb the tool takes as a plain word passed (`pmset sleepnow -g`, `spctl -v developer-mode enable-terminal`, `csrutil
disable status`), and so did a word the shell makes into an option (`networksetup {-setairportpower,en0} off
-getinfo`, a glob). A line of these tools is a read only in the exact shapes of their reads: `csrutil status` or
`authenticated-root status`; `pmset -g` and at most one word; for the others a first word that is a read option, no
other option that is not, and for `spctl` a plain word only as what `--assess` looks at; and, for all nine tools,
no brace or glob (`defaults -host {localhost,write,…} read` is a write).

**Checked.** `tests/unit/test_shell_policy.py`: forty-one lines of these tools, each a query or a change (lines only;
none is run), the reviews' lines among them, and every test of the policy and the shell. A probe of the guard's
verdicts before and after; the independent security review tried the families of diskutil, wrappers (`sudo`, `env`,
`xargs`, `find -exec`), quoting, case and separators, which hold.
