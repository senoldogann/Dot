### 1292. A held secret is masked in each form a text writes it in, by one function

**Status: done (2026-11-21).** The masks of a secret Dot holds (`mask_known` and its users, `redact_known`,
`mask_filled`, what a tool returns, an event, the tail of a log, a note) matched only the value as it stands, while
`vault/masking.py` knew the JSON, URL and form forms for the values a login filled into a page. A command that printed a
held value as a JSON string, in an address, as HTML or as base64 showed it whole to the run and to the screens.

`core/secret_forms.py` now holds the one list of forms (`forms_of`: as it is, JSON-escaped, URL-encoded with `quote` and
`quote_plus`, form-encoded, HTML-escaped, base64 standard and URL-safe, padded and not, at the three byte alignments
inside a longer text, and each with its blanks folded) and the one mask (`mask_values`), which keeps the compiled forms
of a set of values, the longest first, so a long output costs one search for each form. `mask_known` (minimum 8
characters, as before) and the vault's `masked` (minimum 4, as before; a base64 form only from 8 characters) both call
it, and the stream mask withholds the start of any form, as it did the start of the plain value. Nothing refuses or asks
more: a text without a secret is returned as it was, and no value shorter than before is masked.

Checked: `tests/unit/test_secret_forms.py` (a value with `"`, `+`, `/`, `=`, `\`, `!` and `é` is masked in each form in a
tool result, an event, a log line, a note and a vault page; a text without secrets and a value under the minimum stay as
they are; a 2 MB output is masked with the forms of the set made once and one search for each, counted, not timed), `tests/unit/test_streammask.py` (an encoded form split between
deltas), `tests/smoke/test_secret_egress.py` (a run's `shell` result shows the run and the events every form masked and
the words around them as they were).
