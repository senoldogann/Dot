### 1915. DotNext's chats can show only the messages: "Show steps" in Settings › Chat and in a chat's This chat sheet

**Status: done (2026-11-26).** The owner's shot of a run with eight "Ran 2 commands" and "Thought" rows between the
agent's words: he wants a mode with only the messages.

What changed (the app only):
- Settings › Chat › Messages › **Show steps** (on, the default: the chat as it was), and the same switch in a chat's
  This chat sheet for that chat alone (kept on the phone, `stepsOverrides`, over the setting). The default stays on: the
  owner chose Show all and reads the steps today, so turning them off is his choice, not a change under him.
- Off, the stream keeps the owner's words, Dot's text, the asks, the helpers, failures and how runs ended; the run at
  work's tool calls (but a failed one) and thoughts are left out (`messagesOnly`), and one live line under the last text
  says what it does now ("Running swift test…", "Searching the web…", "Thinking…"), shimmering, replaced in place, gone
  when the run ends (the work line of item 1769). A tap on it shows the steps; a finished run keeps its "Worked for 2m"
  fold, built with every step, so a tap there shows that turn's steps: nothing is lost.
- The modes of Settings › Appearance › Tool calls in chat stay for who wants them; Show steps on keeps whichever is
  chosen there.

How it was checked: `ChatUITests.testShowStepsOffLeavesTheMessagesAndOneLiveLine` on the `n2-queue` fixture with Show all
chosen: the thought row shows, the This chat sheet's switch turns Show steps off, the rows go and the run's one line
shows (the fixture's run waits, so it is the waiting line of item 1909).
