### 1096. A run that starts brings no notification to the phone

**Status: done (2026-11-10).** Asked by the owner: "even when I start a Dot chat on the phone a notification pops up at
once; I don't want that. Only when the session is over, and only if I allowed notifications."

Cause: the lock screen's card (item 1093) was started by the daemon with a push-to-start, and Apple has such a push
carry an alert: every first run lit the phone with "Dot · A task started". An activity opened by the app while it is in
front brings none.

The owner chose (2026-11-10), of three ways offered: the card opened by the app, without a notification (recommended),
over no card at all and over the card with its notification as before; and a notification while a run waits for them
(an approval, a question), as before.

Now:
- The daemon sends no push-to-start, and the app no longer gives its token (`start_token` is sent as `null`; the
  column stays, unused).
- The web UI posts `{type: "working"}` to the app's bridge after a request that starts a run (`POST /runs`, a resume,
  a loop, a queued message); the app opens the activity with no row unless one is up, and the daemon fills it once its
  token comes. A token that comes before the run's start does not end the activity for having no row: it waits a
  minute (`OPEN_WAIT_S`), and one whose request started no run after all (a message queued behind a held queue, the
  pre-push review) ends then. A resumed queue opens it too.
- A run started on the Mac or by a schedule opens no card. The owner is notified when a run of theirs ends or waits
  for them, through the alerts as before, which iOS shows only while Dot's notifications are allowed.
- The owner's swipe no longer needs the daemon to hold back a start: the app opens a new card only at the next run
  started in it (`LIVE_DISMISSED_EVENT` is gone).

Checked: `tests/unit/test_apns.py` (no push goes at a start, none to a start token, the activity the app opened is
filled and ended, a token before the run waits for it, one with no run ends after a minute; no Live Activity push carries an alert), `test_phone_limits.py`,
the iPhone app built for a device.
