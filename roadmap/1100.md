### 1100. A refused script names the tab a login was filled into

**Status: done (2026-11-10).** Found by Dot in its own record: `browser_eval` refused eleven times in several runs with
"a login from the password manager was filled into a tab of this chat".

Cause: no script runs in a chat's tabs while a tab a login was filled into is open (item 493), which is meant. The
refusal said "close it (browser_close_tab) and go on in a new one" without saying which tab: `browser_close_tab` with no
index closes every tab but the current one, which was the filled one, and a new tab opened beside it is refused too, so
a run that followed the words was refused again.

Now the refusal names the tab by its number and the call that closes it (`browser_close_tab` with that `index`), says
that a new tab is refused as well while it is open, and `browser_eval`'s description says so before the run tries. The
rule itself is unchanged.

Checked: `tests/smoke/test_vault_fill.py`, whose yolo test now opens a new tab beside the filled one and is refused with
the tab's number before it closes it.
