### 1238. A character set or a configuration that cannot be read is said, not a traceback

**Status: done (2026-11-19).** Two errors of the code review of 2026-11-19:

- `web/text.py` `decode_body` (finding WEB-07) turned an unknown character set into a `WebError` but not a codec that
  takes no `replace`: a page that declared `charset=idna` raised a bare `UnicodeError`, which the crawl's guard for
  one unreadable page did not catch, so it ended the whole `web_crawl` and lost the pages read before. It is a
  `WebError` now, and the page is left out with its reason as an unreadable one is.
- `config.py` `_read_toml` (finding CFG-02) turned TOML it cannot parse into a `ConfigError` but not bytes that are no
  UTF-8: the daemon and `dotx` said a traceback that named neither the file nor the place. It is a `ConfigError` with
  the path and the byte. So is the same file read by `config_edit.py` `browser_values`, which the pre-push review
  found let it through as `_edit_all` beside it did not.
