### 1215. The plugin scout stops at GitHub's 401 and tells the owner of a blind night the same morning

**Status: done (2026-11-18).** The scout read GitHub with an expired token for six nights (2026-11-12..17, and again
on the 18th): each lead failed alone with "GitHub answered 401", 201 failures, and the only trace was the line under
Customize › Plugins. Found by the research of 2026-11-18 (`reports/agent-capabilities-2026-11-18.md`, PLG-P01).

- `plugins/scout_sources.py`: `TokenRefused`, raised for a 401 to a request sent with a token; `GitHub.token_refused`.
  A 401 without a token stays an ordinary failure.
- `plugins/scout.py`: the night ends at the first refusal, its line says "GitHub refused the token", and the state
  says why the night was blind (`blind`: `token`, or `failed` when looks failed and GitHub answered none of them).
- `plugins/scout_service.py`, `scheduler/runner.py`: a blind night is told to the owner when it ends, through
  `tell_owner`, in their language (`channels/words.py`), opening Customize › Plugins. Nothing changes for a night that
  worked, and nothing is asked or held: the tell only says.

The pre-push review found that the refusal was swallowed by the loop over the scout's sources (three marketplaces
and four topics each failed before the night ended), and that a failed source did not count, so a night with no source
answering was not blind: a refusal now ends the sources' loop too, and a failed source counts as a failed look. Its
second round found that one failed lead in a night GitHub otherwise answered made the night blind and would have told
the owner each morning: a night is blind now only when GitHub answered none of its requests (`GitHub.answered`). The
tell's title is in the owner's language; its text, as other tells', stays English (the Turkish readout of tell texts
is its own item).

Checked: `tests/unit/test_scout_night.py` (a refused token ends the night after one request; a night whose every look
failed is blind, one that worked is not; `blind_reason`; GitHub's 401 with and without a token; the tell and its
Turkish title).
