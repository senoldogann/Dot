### 1003. A question asked once writes no prompt cache

**Status: done (2026-11-06).** **Why.** The Claude Console's caching page showed Claude Opus 5.5, the owner's review
model, with 6.2 million tokens written to the prompt cache in a week and none read (2026-10-31 to 2026-11-06). Every
Anthropic request carried the automatic cache mark, but the review model's questions (the nightly scout, memory,
playbook and owner reviews), like every other side call, are a system message and one user message asked once: each
paid a quarter more than the plain input price to write a cache nothing read. Dot's log held 45 such Opus calls on the
nights of 2026-11-05 and 2026-11-06, every one with no cached token; the Console's writes at 01:00 UTC match them.

**Built.** `ChatRequest.prompt_reuse` (`llm/types.py`, `PromptReuse`): `conversation` for a run's steps, `single` for
every call asked once (review, compaction summary, recap, aside, busy, offers, vision, consult, the proactive judge, the
page extractor, the scout's review). The Messages codec (`build_messages_body`) adds the automatic cache mark only to a
conversation; the settled mark of item 237 was already only on a step's request. Docs: `docs/models.md`.

**Checked.** `tests/unit/test_cache_mark.py` (a question asked once carries no mark for Anthropic nor for OpenCode Go's
Messages route, a step carries the automatic one); `tests/smoke/test_wire_codecs.py` and the tests of every caller.
