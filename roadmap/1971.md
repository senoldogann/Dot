### 1971. The pre-push hook checks the prompt surface before it asks a model

**Status: done (2026-11-26).** A change to `.claude/hooks/pre-push-review.sh` applies to the owner only once their own
checkout has pulled it.

Main went red twice in one day because a merged change edited a tool's description or a prompt and
`tests/fixtures/prompt_surface` was not written again: `tests/unit/test_prompt_surface.py` runs on macOS only (the
render loads AppKit through `desktop/apps.py`), and a pull request runs the Linux jobs.

- `scripts/prompt_surface.py --check` writes nothing, prints the stale files and the command that fixes them, and exits 1.
- The hook runs it, in seconds and before the plan and the model review, when the pushed change touches `src/dotagent`
  and `scripts/prompt_surface.py` exists, and stops the push with `uv run python scripts/prompt_surface.py` and the
  folder to commit. It reads the working tree, so it checks the branch that is checked out, and only while
  `src/dotagent`, the script and the fixture folder have nothing uncommitted (else it stops: what is pushed could not be
  checked); a push of another branch says it was not checked. The script exits 3 for a stale fixture; any other failure
  stops the push with its own output, not as a stale surface.

Checks: `tests/unit/test_pre_push_hook.py` (a fresh surface lets the review go on, a stale one stops the push and no model
is asked, a change outside `src/dotagent` runs nothing, a failed check is not called stale, uncommitted changes stop the
push, a branch not checked out says so).
