### 1279. The home and the office's panel have no New chat: an agent has one chat

**Status: done (2026-11-20).** The owner's decision of 2026-11-19 (Dot is agent-first: each agent has one purpose and one
lasting chat, and no new chat is opened all the time) was built in items 1233 and 1245, which made a message from the
home go on in Dot's home chat. Two buttons still said the opposite, found by the UI audit of 2026-11-20, and the page
was still called what it no longer is:

- **The home** (`views/runs.js`): the **New chat** under the box, which made the next message start a chat of its own,
  is gone with its `fresh` flag; **Open your chat with Dot** stays, and `whereTo` has one rule: the home chat of the
  one the box writes to.
- **The office's panel** (`office/office.js`): its **New chat** and the `freshChat` set behind it, and the note "Your
  next message starts a new chat.", are gone; the panel is the agent's one chat.
- **The names**: the route's title, the hidden heading and the box's label read **Chat** (the tab: `Chat · Dot`; it read
  New chat), and the PWA's long-press shortcut is **Chat** (`manifest.webmanifest`).
- **Kept on purpose**: **New chat** in an agent page's "…" (`views/agents.js`) is the one way to leave a conversation, a
  deliberate step the owner takes on a page of one agent, and the desktop shell's ⇧⌘Space menu item, which only brings
  the window to the home.

Tests: `home_afresh.start_afresh` (used by `test_voice`, `test_composer_picks`) now leaves Dot's conversation by deleting
it, since the button is gone; `test_agent_conversation` and `test_office` assert there is no New chat and that the face
and the panel stay on the one chat; `test_composer_words` and `test_one_message` make the chat of another model after
the home's own message instead of before it; `test_manifest` names the shortcut. `docs/daemon.md`,
`docs/agents-and-campaigns.md` and `docs/phone.md` say it.

Checked: `npm run check` (372 JavaScript tests), the unit tests (7,218), and the browser tests of every file touched
