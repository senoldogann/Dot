### 2028. DotNext shows charts and reports in the conversation

A page a run shows now appears where its event was recorded in the chat, including after a cold reopen. The
existing chat view includes page references for its run window. The phone combines these references with its
live timeline without moving the stream cursor or fetching the pages before their cards come into view.

The phone loads the existing page route on its paired Mac. WebKit admits the first sandboxed HTML response
at that address and uses a non-persistent data store. Page scripts receive no phone key or application bridge.
The inline preview fits up to 2,000 points. A tap opens a scrollable, full-screen viewer with Close. The web and
phone use the same English and Turkish names for the shared controls. On touch screens, the web's page controls
have 44-pixel targets.

DotEngine tests cover event order, duplicate delivery and the cached view. The server test covers references
from earlier runs in the chat window. The browser test exercises the viewer in Chrome at 1440×900 and 390×844,
and the iOS fixture test covers fitting and opening a sandboxed page with Turkish controls in dark appearance.
The owner has yet to see the feature on the real iPhone.
