### 2099. The web's file panel draws code, Markdown and grids a page at a time, through item 2017's code view

**Status: done (2026-11-28).** The web half of item 2098: the file panel already formatted a Markdown file (item 269)
and drew a CSV as a grid, but drew every line, block and row at once, and coloured a source file with a scanner of
its own that item 2017's `diffview.js` had since outgrown.

What changed:
- `codeview.js` holds the change view's code view (out of `changes.js`), and `lazylist.js` the drawing a page at a
  time it used (`appendInPages`). The file panel draws a source file with it (a JSON file laid out by `prettyJSON`,
  the language from `changeFormat`, or for a language diffview.js has no grammar of the nearest one it has: C, C++, C#,
  Java, Kotlin, PHP and Dart by JavaScript's, Ruby by Python's, INI by TOML's, Vue and Svelte by HTML's; SQL is numbered
  uncoloured, where the old scanner coloured its strings, numbers and the few keywords it shared with the others,
  such as `and`, `or`, `in`, `from`, `where` and `null`), and a Markdown file's source numbered
  in it; its own tokenizer and its CSS are gone. The code view fills the panel and is what scrolls.
- A Markdown file is drawn 120 blocks at a time and a grid 200 rows at a time as the panel scrolls to them, with the
  chat's `blockNode` (a table in its sideways scroll box, as in an answer).

Measured on a throwaway daemon (`e2e_daemon.py`) in headless Chromium, from the open to two frames after the content,
1440x900 and 390x844 (before → after): a 200 KB Markdown report 306 → 186 / 147 ms and 15,165 → 3,154 nodes; a
5,000-row CSV 499 → 324 / 254 ms and 28,041 → 1,442 nodes; a 250 KB JSON file 374 → 104 / 141 ms; a 4,000-function
Python file 751 → 84 / 108 ms and 68,036 → 2,134 nodes, its worst scroll step 82 → 42 ms. The daemon's read of the file
is 5-80 ms of each.

How it was checked: `npm run check`; `tests/smoke/test_file_panel.py` (a Markdown file's table drawn as a table, its
source in the code view, a Python file numbered and coloured by `diffview.js`, a CSV of 253 rows drawn 200 at first
and whole once the panel scrolls to its end) and `test_changes_panel.py` (a web
page's source) on GitHub's browser run; screenshots at 390x844 light and 1440x900 dark of a report with a 29-row
table, a 5,000-row CSV and a JSON file.
