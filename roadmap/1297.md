### 1297. A run is told when Chrome quit under its tabs, and a quiet read's failed close no longer replaces the page it read

**Status: done (2026-11-22).** In Dot's own Chrome, a Chrome that quit or crashed took every run's tabs with it
silently: Chrome closes the pages one by one (each leaves its thread through `_on_page_closed`) and then tells the
context is gone (`_on_context_closed` -> `_forget_tabs`), the next call found no tab and made a blank one, and the run
went on with refs from a page that no longer existed. "Chrome was closed" was said only in attach mode. And
`_close_scratch`, called in the `finally` of a quiet read, could raise "closing a tab failed" and replace the page the
read had already got.

`ThreadTabs` has `tabs_lost`, set by `_forget_tabs` for a thread that still listed tabs or whose last tab closed (not by
Dot) in the 5 seconds before (`emptied_at`, set by `_on_page_closed`), in both modes. `_locked` raises, once, `BrowserError("Chrome was
closed or crashed; your tabs and refs are gone; open the page again")` to the first call of that thread afterwards, after
the browser is connected again so that the next call works; `browser_open`, `browser_new_tab` and the owner's own
flows that open a page (`opens=True`) go on instead, in a new tab whose view carries the same note. A thread that held no
tab is told nothing, and a Chrome that Dot itself closed when idle (`_let_go`) sets nothing, as before. The `finally` of
`_read_page` calls `_discard_scratch`: a close that fails (`BrowserError`, Playwright's own errors) is logged, the page is
kept in `_stray_scratch`, and the reaper's next round (`_close_strays`) closes it again; any other exception is still
raised.

Checked: `tests/smoke/test_browser_chrome_lost.py` on real Chrome (a SIGKILLed Chrome: the first call of each chat that held
tabs is told once and the next goes on; `browser_open` after it carries the note once; a chat that held no tab is told
nothing; a read whose tab will not close returns its page, and the reaper's retry closes the tab), with
`tests/smoke/test_browser.py` (the dead-driver test: one failed call, then `browser_open` works) unchanged.
