### 506. A run's steps read as a list: the command as code, a read with an eye, a thought in italics

**Status: done (2026-10-21).** Asked by the owner, with two screenshots of t3code's timeline: the stream of what a run
does should read as tidy as that one. Dot's stream already had the same anatomy — a group's line ("Ran 2 commands and
read 1 file") that folds, a row for every call with the mark of its kind and a chevron, the screenshots in the flow, a
thought's line. Four details kept it from reading as calmly: a command was set in the interface's own type and cut to a
line, so it never looked like the code it is; opening a command showed its arguments as JSON; a read or a write repeated
its tool's name (`read_file`) before the words the policy already had ("Read notes.txt"); and the start of a thought
stood in roman where t3code sets the thinking in italics.

**As built.**
- `js/tools.js`: a command's row carries the `command` class, and opened its first section is the command itself under
  "Command" rather than the call's arguments as JSON — the command over its output, as t3code draws it. A call of the
  kind read or write keeps no tool's name any more: its mark and the policy's words say what it did, and the row's width
  goes to the path instead.
- `js/icons.js`: a read (`read_file`) wears the eye, a search of the files (`find_files`, `search_files`) the magnifier,
  a write (`write_file`, `edit_file`) the sheet of paper, and a folder's listing (`list_dir`) a list, since a sheet of
  paper is a write's now and the group a listing counts in is not a read's.
- `css/app.css`: a command's words in the monospace type, a touch smaller than the prose; the start of a thought in
  italics.

**Checked.** `npm run check` green (43 tests). The browser tests of the rows, in Chrome against a daemon of this branch:
`tests/smoke/test_flow_fold.py` (2 passed, with the read and the write now told apart by their marks and words),
`test_phone_rows.py`, `test_thread_turns.py`, `test_chat_calm.py`, `test_sunshine.py`, `test_why_it_ran.py` and
`test_thinking_blocks.py` (13 passed), so the phone's row heights (28–36 px in a pitch of 34) and the thoughts' blocks
hold. Clicked through a run with two commands, a read and four thoughts at 1 280 and 390 px, light and dark: the
command reads as code, the read wears an eye and no tool name, a thought's start is italic, and an opened command shows
the command over its output.
