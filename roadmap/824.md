("tüm projeyi gerçekten incele ... eksiklerimiz varsa düzeltelim"): four runs of 2026-10-22 ended "a stored screenshot
file is missing", the night a folder was deleted by mistake. Dot removes only the screenshot files no message or event
names, so a file goes missing only by something outside it; but then every run of that chat failed as its history was
read back, and the chat could not be used again.

- `_read_image` (`dotagent/store/db.py`) reads a file that is gone as none, logged as `screenshot_missing`; the
  message is read back without it, its other screenshots and its text as they were.

other, and the log names the missing one.
