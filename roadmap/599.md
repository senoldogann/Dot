### 599. A folder of third-party files is known whatever the letter case it is named in

**Status: done (2026-10-23).** Item 598's review found that the folders where Dot keeps what third parties wrote
(`<workspace>/crawl/` and `<workspace>/mcp-results/`, item 494) were compared as written: a Mac's volume ignores letter
case, so `read_file("CRAWL/host/001.md")` reads the crawl's page, but resolving a path keeps the case it was written in
(`realpath` follows links, it does not respell names), and `Path.is_relative_to` compares letters. The page was read
back without the untrusted mark that reading it marks again after the owner's message cleared it.

**As built.**

  (`within`, item 116): `holds_third_party` (`read_file`, `search_files` of a file or folder, `show_page`),
  `matches_third_party` (a search's lines) and, for a shell line, the folder it runs in (`mentions_third_party`).
