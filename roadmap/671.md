### 671. An MCP tool with a deep schema leaves its server in

**Status: done (2026-10-26).** The owner: "we never solved the MCP problems in Dot, always errors". Vercel's
connector stood **Left out**, "the input schema of an MCP tool cannot be used": the log named `update_flag`, whose schema
"nests deeper than supported". One tool's schema kept every Vercel tool out of every run (item 175 made it a failure of
the server so that Dot still started).

**The change.**
- `tools/schema.py`: a reference to a definition its own path already went through is cut where it first comes back,
  as is a part past twelve levels or a reference to a definition that is not there: to a loose schema of its kind (an
  object, a list of objects, or the scalar type its definition or its list of types says, `null` left out), its
  description kept and saying that its parts nest deeper than shown. The rest of the schema stays whole, and the
  service checks what the model sends for the cut part. A flattening that makes more than 5,000 parts, or a flattened
  schema longer than 32,000 characters, is refused, as one whose top is no object: a tool's parameters go with every
  request of every run that has it.
- `mcp/hub.py` `usable_tools`: a tool whose schema is refused is left out alone and logged (`mcp_tool_left_out`), and
  its server's other tools serve; a tool the `allow` list names, and a server left with no tool, leave the server out
  with the reason, as the owner set it up otherwise.
- `docs/extending.md` says so, and `mcp/catalogue.py` no longer gives a deep schema as why Bright Data is left out.

**The review's finding, first try.** Cut only at the depth limit, a definition that refers to itself from several
places (a GraphQL `where` filter: `_and`, `_or`, `_not`) was written out k^12 times: the daemon's loop held for minutes
and the schema went with every request. Cutting where a reference comes back on its path, and the two limits, closed it.

**Checked.**
- `tests/unit/test_deep_tool_schemas.py`: a schema that refers to itself, one twenty levels deep and a reference to
  nothing are cut, their top kept; a filter that refers to itself three times over flattens in under a second to
  under 2,000 characters; a cut part keeps the kind of its definition and of `["string", "null"]`; a schema too long
  once flattened is refused; of three tools the one whose arguments are a string is left out and the deep one kept; a
  tool on the allow list that cannot be used, and a server with no usable tool, leave the server out; an optional part
  that was cut keeps saying so under the field's own description.
- `tests/smoke/test_mcp.py`: a real MCP server whose tool takes a tree serves beside another, its tool's parameters
  saying where they were cut (it was left out since item 175).
- On the owner's Mac once deployed: Vercel's **Check again**.
