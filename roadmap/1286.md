### 1286. Dot no longer trades: the trading desk, the trend engine and the Coinbase account are removed

**Status: done (2026-11-21).** The owner asked for it after the paper account lost 11.7 % in 23 days (1,000 → about 882
USDC, 29 Oct to 21 Nov; holding BTC lost 28 % over the same time), with a rule engine whose backtest was below holding
in a rising market. No run made money with it, and nothing in it was to go live. It was kept only as cost: a module, a
tool group, a policy flag, a settings page, an agent and a daily schedule to carry.

What changed, and what stays:

- Removed: `dotagent.trading` (the Coinbase market and broker, the paper account, the limits, the trend rule and
  engine, the watch of exits and of the market), the `trading` tool group and its prompt section, the `[trading]`
  configuration table, `dotx trading backtest`, the `/api/trading` routes, Settings › Trading, the Trader agent
  template, the `trade` policy flag with its guard and decision source, and the Coinbase host from the egress list.
  The schedule a move of the market started (`fire_for_signal`) went with it: `fire_by_hand` is now the one way a run
  starts out of its time, with no signal to branch on.
- Schema version 2 (`db._MIGRATIONS`): the `trading_orders` and `trading_exits` tables are dropped from a database that
  has them. A database below version 2 is copied first (`backups-before-upgrade/v1`), so the paper orders (14, no live
  one) are in that copy. A database of version 2 is refused by a Dot of version 1, as every later version is.
- A `[trading]` table left in `config.toml` is refused at start (a key this version does not have), so it is taken out
  of the file in the same deploy. No stored approval, event or rule holds a `trade` flag or source (checked in the
  owner's database), so nothing already kept fails to read.
- Not changed: `financial` still hands a payment to the owner, and the other guards keep their order. The general
  edit of a number with decimals in `config_edit` (item 771's fix) stays, its test now on an arbitrary key. No Coinbase
  key was ever stored for the paper account; there is nothing in the Keychain to remove.

Checked: ruff, mypy; the unit tests (a version-1 database with trading tables and rows is brought to version 2, the
tables gone and the copy holding them); the smoke tests of the screens and tests this touched.

Log:

  engine switched off first, with `config.toml` copied beside it.
