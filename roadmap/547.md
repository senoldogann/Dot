### 547. A file wears its language's own logo in the side panel

**Status: done (2026-10-23).** Asked by the owner: in the Artifacts area each programming language should show its own
SVG icon or logo, not the letters of its kind.

**As built.**
- `static/icons/languages/`: 38 marks from Simple Icons 16.35.0, released under CC0, each the icon's path alone with
  the brand colour Simple Icons gives it as the file's fill: python, javascript, typescript, rust, go, markdown, json,
  css, sass, html5, xml, svg, gnubash, openjdk, kotlin, c, cplusplus, dotnet, php, ruby, sqlite, toml, yaml, swift,
  dart, vuedotjs, svelte, lua, r, scala, elixir, haskell, perl, clojure, jupyter, docker, gradle and cmake. The
  folder's `LICENSE` names the version, the licence, every file and the owners' brand guidelines, so the licences page
  lists it as a bundled notice.
- `static/js/contextpanel.js`: `LANGUAGE_MARKS` names a slug for 58 extensions, `WHOLE_NAME_MARKS` names Dockerfile and
  CMakeLists.txt (which have no extension to read), and `languageOf(path)` reads a file's own name before its
  extension, null for a kind with no mark.
- `static/js/contextpanelview.js`: `fileMark` draws the logo as an `<img class="context-logo">`; a kind with no mark
  keeps the letters of its kind on their tile, and a name with no short kind keeps the folded page.
- `static/css/run.css`: `.context-tile-logo` keeps the light ground and ring a service's mark wears
  (`--mark-ground`, `--mark-ring`), so a dark logo (Rust, JSON) reads in the dark scheme too; the logo is 16 px in the
  26 px tile.
- `docs/daemon.md` says a file wears its language's logo, or the letters of its kind where the language has no mark.

**Tests.** `tests/js/contextpanel.test.js`: `languageOf` reads py, TSX, md, toml, rs, html and yml, reads a Dockerfile
and a CMakeLists.txt by their whole names, and finds no mark for a Makefile, an unknown extension or `.gitignore`.
`tests/smoke/test_context_panel_page.py`: a run that wrote a Python, a TypeScript, a Markdown and a Rust file shows
four language tiles, no letter tile, and the four logos' paths. `tests/smoke/test_about_pages.py`: the licences page
lists `icons/languages` among the bundled notices. `npm run check` (biome, tsc and the 77 JS tests), `ruff` and `mypy`
pass.
