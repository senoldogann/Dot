### 1256. The pre-push review runs on the owner's Claude plan, starts from the change, and its chats leave the owner's list

**Status: done (2026-11-20).** The owner asked why Dot keeps opening review chats and why each takes so long. They are
the pre-push hook's (`.claude/hooks/pre-push-review.sh`), started by the coding sessions' pushes through `dotx run`,
one chat per branch, each a plain `cli` chat among the owner's own. Measured on the owner's Dot: 12 reviews took 6 to
27 minutes, 29 to 131 steps and 2.8 to 14.5 million input tokens on `opencode_go:deepseek-v4.1-flash` at effort high,
most of the steps spent reading a change the hook had written to a file. And since item 1245 Dot's home chat is the
latest `ui` or `cli` chat with no agent, which was a review chat after every push.

- `dotx run --review` starts its run with the source `review` (in the command's own process and handed to the daemon,
  whose `POST /runs` takes `review` beside `ui` and `cli`). The sidebar keeps those chats under **Code reviews**, folded
  until opened, as it keeps Dot's work and the agents' work; Dot's home chat reads only `ui` and `cli`, so a review is
  never it. The prompt weighs a review as the owner's request, as a `cli` run.
- The hook runs `claude_code:opus` at effort medium (the owner's choice), with no goal mode (a checker sending a
  verdict back to work only lengthens it), and puts the change itself in the goal while it is at most 40,000 characters
  (the daemon takes 50,000; half of the 546 diffs the hook wrote were under 21,000), read from standard input, so the
  review starts from it, in the first review of a branch's chat. A larger change, and a later round's, are read from
  the file as before: the chat's earlier goals reach its judges as instructions, which a diff in each would swell.

Item 1211 moved the review off Claude Code once, when it answered `[cyber]` to a diff. A review with no verdict (a
refusal, a spent plan) is done again on `opencode_go:deepseek-v4.1-flash` at effort high, in a chat of its own (the
owner's choice); a second one with no verdict stops the push.
