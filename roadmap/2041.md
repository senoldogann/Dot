### 2041. Task notifications use the goal check's outcome and the same words across surfaces

**Status: implemented (2026-11-27).** Notify on a question or approval and on the stored end of a task that succeeded, failed or was blocked. A final
goal check can distinguish a blocked end while the run keeps its existing stored status. A progress event or
a stop does not send a task notification. The phone and web use fixed English or Turkish task copy and send
the owner to the chat for details.

Checked with Web Push and fake APNs tests. The browser smoke tests exercise the page's own notifications.
