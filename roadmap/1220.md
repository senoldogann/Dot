### 1220. An eval measures and cuts a run on the Claude plan, and leaves the plan's window for the owner

**Status: done (2026-11-18).** `dotx eval run --model claude_code:sonnet` (the owner's main model) was wired but could
not be trusted (`reports/agent-capabilities-2026-11-18.md`, ARC-02): the eval's watch read a run's spending only at a
`model_call` event, which a run on the Claude plan or on OpenCode does not record (the program runs the whole goal and
Dot sees its steps), so the 600 000-token budget never cut such a run; and the scorecard read cached tokens, the
largest context, the model's seconds and the calls from those events alone, so a plan run showed none of them.

- `evals/metrics.py`: `model_calls` gives a run's `model_call` events, or, when it has none, the `assistant` event of
  each step, which every way of running a goal records with the step's tokens, cached tokens and seconds. The cached
  tokens, the largest context, the model's seconds, the call count and the trace read it.
- `evals/runner.py`: the watch reads the spending at an `assistant` event too. An attempt on the plan is cut
  (`plan_window`) once the window it runs in is 70 % used (`PLAN_WINDOW_MOST`) or refuses calls, read from each step's window and, for a run the window refused before
  its first step, from the error kind its `run_finished` event keeps (`ended_by_plan_limit`); the owner's
  recommended cap (D1, taken as their go-ahead on 2026-11-18) leaves the rest of the plan for their own work.
- `cli_eval.py`, `harness/probe.py`: such an attempt is not scored (it says nothing of the model): the eval run stops
  and says so, and a probe stops with `cut_short = "plan_window"`.
- Not done here (the rest of ARC-02): a weekly spend ledger across eval runs, hard stops at fixed night hours and a
  one-task smoke run against the real plan.

Checked: `tests/smoke/test_claude_code_run.py` (a run on a stand-in `claude` is cut at a 50-token budget; it was not
before the change; a run its plan refused is told from its end), `tests/unit/test_eval_plan_runs.py` (a plan run's numbers from its steps, a loop run's from its
model calls alone, the window's limit), `tests/unit/test_evals.py`.
