### 916. The model that decides Dot's own work is chosen in Settings › Models, and a costly try no longer lets big work go at once

**Status: done (2026-11-02).** **Asked** by the owner after items 910 and 913 were deployed ("config.toml kimi-k3
yazdın ama bu ayarı biz arayüzde neden göremiyoruz? Ayrıca 5M tokenden fazlalık bir iş ise o zaman sorun olmaz mı").

Item 910's `[initiative] look_model` was only in `config.toml`: nothing in the web UI showed it or chose it. Item 913
let a thing go after one failed try that spent more than 5 million tokens. Measured on the owner's store (2026-10-29 to
11-02): 13 of the 55 initiative runs that did their thing spent more than 5 million, one 14.3 million. A big thing whose
first try failed (a network drop, a step limit) would have been let go though a second try could finish it. The tries
also never heard how the one before ended, so each started from the start: the waste item 913 was about.

- `llm/roles.py`: `ModelRoles` holds the look model too (`look()`, `choose_look()`); the look reads it there, so a
  choice holds from the next look with no restart.
- `PUT /api/initiative/look-model` (`""` for the default model) writes `[initiative] look_model` through
  `config_edit.set_look_model` and refuses a model that cannot use actions or one of Zen's free models.
  `GET /api/initiative` says `look_model` and `costly_tokens`.
- Settings › Models: an **Own work model** row under the roles, with **Default model** as its first choice.
- The On its own card on Schedules says which model decides (a link to Settings › Models) and what a costly try comes
  to. Its lines under the lead are set in as the lead is (the dearer hours' line of item 826 was not).
- `proactive/initiative.py`: a failed try past `retry_under_tokens` is a costly one, its note "Spent X.XM tokens without
  doing it: …"; a second costly try in a row lets the thing go ("A second costly try. …"), before `attempts` are used
  up. A try after the first is told what the one before spent and how it ended, read from that run (never from the
  thing's note, which a try the daemon's stop cut off leaves as an earlier run wrote it), quoted only of a run that read
  nothing third parties can author (item 911's rule), and goes on from what it found. A run's answer that reads as a
  costly try's note is kept as "It said: …", so that only Dot marks a costly try.
- `docs/proactive.md`, `docs/models.md`, `docs/daemon.md` say so.
