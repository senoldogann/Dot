### 521. Pages that live, drawn whenever an answer has a shape

**Status: done (2026-10-22).** The owner asked for more of what `show_page` draws in the conversation: 3D charts,
tables, animated tables and diagrams, as often as they fit.

**As built.**
- The Pages section of the system prompt asks for a page whenever an answer holds figures to compare, a trend, a
  ranking, a share, a timeline, the steps of a process, how parts connect, a place or a layout. It prefers a page to
  a long list or figures in text, one page a question and none for a single number.
- It asks for a page that lives: animated in, with values on hover, tables that sort and series that switch, and still
  under `prefers-reduced-motion`.
- It names the libraries that fit, in pinned versions from cdn.jsdelivr.net: Apache ECharts or Chart.js, Mermaid, D3,
  three.js.
- `show_page`'s description and the `pages` group's line say the same.
- What a page may load is as before (`agent/pages.py`, the page CSP in `server/guard.py`), and every library named
  there loads.

Checked by `tests/unit/test_tool_groups.py` (the group's line) and the unit suite.
