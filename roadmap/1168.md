### 1168. A run nobody watches closes its tabs when it ends, and a chat's tabs and Dot's Chrome close after 10 minutes

**Status: done (2026-11-13).** The owner saw Dot's tabs stay open after an agent's work was done. The live log of
2026-11-13 showed the tabs did close (59 chats' tabs, Chrome itself 27 times, no failure logged), but only half an hour
later: a run's end closed its background tabs and kept the current one for `tab_idle_s` (1800 s), and Chrome stayed
until `idle_close_s` (1800 s) after that, so as not to take a page from a message that goes on from it.

**Built.**

- A chat that a run nobody watches opened (a schedule's, a watcher's, Dot's own initiative, a reply: item 699's
  `UNWATCHED_SOURCES`, read from the chat's own source) closes every tab when such a run in it ends with no question
  left, as a helper's chat did already: no message goes on from it, so its last tab only held Chrome open
  (`keeps_current_tab` in `agent/manager.py`). The owner's chat keeps its current tab whoever ran in it last: a loop
  of the chat and a reply in it are schedule and reply runs too (the pre-push review), and a run that asks keeps it
  for the answer that goes on from it. A chat deleted after the run's end was stored closes all its tabs.
- `tab_idle_s` and `idle_close_s` are 600 s by default, from 1800 s. A chat the owner works in keeps its current tab for
  ten minutes after its run; Chrome closes ten minutes after nothing uses it, still not while its window is in front.

**Checked.** `tests/smoke/test_run_end_tabs.py` runs an owner's run, a helper, a schedule's run and a loop of an
owner's chat in the real loop and reads what the browsers were told; `tests/unit/test_keeps_current_tab.py` holds the
rule, a run that asks among it; `tests/smoke/test_browser_tabs_tidy.py` closes real tabs.

**Not done.** Nothing measures how often the owner went on from a page more than ten minutes after a run ended; a
config's own `tab_idle_s` still overrides the default.
