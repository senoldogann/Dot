### 520. An Ollama model of this Mac gets the window its context size needs

**Status: done (2026-10-22).** Reported by the owner: local models in Ollama, whose own settings gave them 128K
(`OLLAMA_CONTEXT_LENGTH=131072`, `context_length` in the Ollama app), showed 48K in Dot, and no agent started on them.

**Cause.** Dot sends `num_ctx` with every request, `[providers.ollama] num_ctx` (65,536) for a model of this Mac, and
the window a request asks for wins over Ollama's own setting. A run's budget is three quarters of the window, 49,152,
under the 53,172 a run's system prompt and tool definitions took (`run_mviirxb2_14edab`), so the run was refused.
Settings › Models offered no more, since its sizes stopped at three quarters of the window Dot asks for.

**As built.** One pure function, `llm.types.grown_window`, gives the window a context size needs: the size is
three quarters of it (`WINDOW_SHARE`), in steps of 1024 tokens, up to the model's own window where Ollama says it
(`own_context_length`).
- `ollama.asked_window` asks Ollama for it with every request.
- `scaffold.run_window` plans the run with the same window. The two never differ, and one window a model keeps Ollama
  from loading it again for each size.
- The context sizes live with the router (`ModelRouter.context_sizes`), which hands them to the Ollama connector. The
  runtime's are the same object, so a size chosen in Settings › Models holds from the next request on.
- Settings › Models offers sizes up to three quarters of the model's own window (`scaffold.window_choices`,
  `most_window`), and `PUT /api/models/context` takes them.
- Without a size the window is `num_ctx` as before, so nothing changes for a model nobody gave one. Dot does not read
  Ollama's own setting, which no API of Ollama gives.

Checked by:
- `tests/unit/test_model_windows.py`: the window each size asks for, and the sizes offered.
- `tests/smoke/test_ollama_window.py`: an Ollama server in the process records `num_ctx` of 65,536, 131,072 and the
  model's own window.
- `tests/smoke/test_context_sizes.py`: the sizes of a model whose window Dot asks for, in the API and on the page.
