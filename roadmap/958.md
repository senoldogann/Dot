### 958. Self-repair reads where its pull requests stand on GitHub

**Status: done (2026-11-03).** **Asked** by the owner with a screenshot of Settings › Self-repair on 2026-11-03: "closed
should read closed and merged merged, or everything reads Waits for you". #764 had been merged and #768 closed (its
fix replayed and merged as #770) by hand, and the page still said *Waits for you* and *Needs you* of both: a session
keeps the end it had, and the night looked again only at pull requests a moving main had stopped (item 933).

**Built.** `repair/settle.py`: `urls_to_read` (each problem's that waits on one, each session's that Dot did not merge
itself, unless read merged or closed already), `with_pr_states` (a session and a problem take `pr_state`; a problem
that waited on a merged one is fixed from now, on a closed one `closed`, a new status no night picks), `read_state`
(`gh pr view --json state`, asked again twice with a growing wait and a warning, the last failure raised) and
`settle_stored`, which settles a problem since GitHub merged or closed its pull request (`mergedAt`, `closedAt`, read
by `github.pr_standing`), keeps the book and the sessions when they changed, and then raises naming any pull request that
could not be read, which keeps the others from nothing (the pre-push review). `Scheduler.settle_repairs` runs it in a task
of its own that a night waits for, and every night runs it first; `POST /api/repair/settle`, which the page calls as it
opens (its polls read `GET /api/repair`, which asks GitHub nothing), starts one when no night is under way and waits
up to 8 seconds. A new session's problem starts with no state. The page (`views/repair.js`) shows
*Merged* or *Closed* for a pull request GitHub says so of, and lists closed problems under *Closed*.

**Checked.** `tests/unit/test_repair.py` (merged, closed and open, what is read and what is not again);
`tests/smoke/test_repair_settle.py` (a stand-in of `gh` on this Mac: a merged, a closed after one failed ask, and an
open pull request, and one that never answers, which the others are kept beside; the second reading asks only of the
open and the unread one).
