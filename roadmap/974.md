### 974. A chat that read a page is read fenced however its runs ended

**Status: done (2026-11-05).** **Found** by the deep review of 2026-11-05 (the owner's ask), three gaps in what marks a
run untrusted:
- `read_chat` and `read_agent_chat` (`tools/office.py` `read_thread`) fenced a chat and marked the reader by whether its
  newest twenty runs *ended* tainted: a run that read a page and was then written to by the owner ended clean, while
  the chat's history, which the reader takes, still held the page's words; a run older than the twenty was not read at
  all. `docs/agents-and-campaigns.md` says what a chat's runs read comes fenced.
- A note of Dot's that carried such content (a chat's note, item 957; a work order; a helper's answer) marks the run that
  reads it through its `steer` event alone, which `chat_ever_tainted` and the mark a chat keeps when the chat that sent
  it work is deleted (`thread_taints`, item 952) did not count: a run that read a note and made no step after it left
  its chat looking clean.
- `RunGate.take` counted every message that reached a run as the owner being there, a note of another run's among them:
  a run whose kept step the owner left unanswered then waited the whole approval time again on its next one (item 482).

**Built.** `read_thread` asks `Store.chat_ever_tainted`: whether a run of the chat ever read such content, the mark of a
deleted chat's run included. `chat_ever_tainted` and the `thread_taints` row count a `steer` event that says it was
tainted (only a note of Dot's says so). `RunGate.take` hears the owner in everything but a note of Dot's
from another run, which `RunManager.note` sends marked so (`UserInput.of_dot`): the owner's own reactions, which reach
the run as notes too, still say they are there.

**Checked.** `tests/smoke/test_office_tools.py` (a chat whose run the owner wrote to after it read a page is read fenced
still), `tests/unit/test_skill_save.py` (a note's mark makes the chat ever marked), `tests/smoke/test_chat_notes.py` (a
note leaves the owner away and marks the run; the owner's words clear both), `tests/smoke/test_delegate.py`.
