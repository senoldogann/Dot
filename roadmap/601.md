### 601. Dot opens a page it showed at its address on this Mac, to see what it showed

**Status: done (2026-10-24).** The owner asked whether Dot should not be able to open what it made at a localhost
address, after its run was refused a `file:` one (items 596, 598). Dot's own browser never opens Dot's interface, so a
run could not look at the page it showed the owner (`/pages/<id>`), though that page is served without the token to
whoever names its id and is sandboxed wherever it opens.

The approach. What must hold: nothing else of the interface opens, the page stays sandboxed, and nothing it loads of
the daemon passes. The exception is the address exactly (`/pages/page_<id>`, no other path, no query), on this Mac at
the daemon's port, as a page or a frame; a request a page makes for it stays refused.

**As built.**
- `browser/safety.py` `shown_page`: `/pages/<id>` exactly, on a loopback host in any spelling at `[server] port`, read
  as the browser reads it (a backslash refused); `check_browser_url` lets it through before the lists, so the model's
  own open, a tab's navigation and a frame pass, and `request_verdict` keeps a script's or a picture's request for it
  refused. The names of `[server] reach` and any other path of the interface stay refused.
- `show_page`'s answer gives the page's address (`page_address`: `[server]`'s host and port, then `/pages/<id>`),
  which the run's browser may open to see what it showed; `dotx run` prints the same.
- `PAGES_PREFIX` moves to `agent/pages.py` with the other constants of shown pages, and `page_address` with it, so that
  the browser's rules and the page tool name a shown page without importing the server; the guard, the pages route and
  the command line take them from there.
- `docs/browser-and-computer-use.md` and `docs/runs.md` say it.

**Tests.** `tests/unit/test_own_interface.py`: a shown page opens as a page and a frame, whatever the lists say, and not
as a resource; `/pages/`, a page id with a slash, dot segments, a query or encoded slashes after it, another kind of id,
capitals, the API's path, the reach name and a backslash spelling stay refused; on another port it is any server of the
Mac. `tests/unit/test_page_by_path.py`: the answer gives the address.
