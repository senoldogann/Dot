### 980. A skill learned in a chat that read a page is marked so

**Status: done (2026-11-05).** **Found** by the security audit of 2026-11-05 (the owner's ask; run-1 lead
`dotagent/agent/playbooks:learn_playbook:taint-mark-ignores-chat-history`): a learned skill took its mark from the run
it was distilled from alone (`Store.read_outside(run.id)`). The owner's "go on" after a page starts the next run of the
chat clean, while the chat's history it reads holds the page's words; a skill learned from that run was written clean,
its writer shown the calls' results and the run's answer, and later runs were offered it whole and read it unmarked.
`skill_save` refuses this very case by the chat's mark.

**Built.** `agent/playbooks.py` `_read_outside`: a run's skill is marked when the run read such content or a run of its
chat ever did (`Store.chat_ever_tainted`), for the skills a run teaches and the ones the owner saves. Docs:
`docs/extending.md`.

**Checked.** `tests/smoke/test_learned_skills.py` (a run of a chat whose earlier run read a page writes a skill marked
so, though it read nothing itself; it failed before the change), the other learned-skill tests.
