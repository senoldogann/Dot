### 654. What the owner disliked reaches the learning

**Status: done (2026-10-25).** The owner asked what happens when they give Dot the same task again after disliking
how it did it, if the agent always uses the same memory for it. The code said it was so:
- a 👎 or 🔁 after a run started a follow-up run that fixed that answer;
- lessons were drawn only when something failed on the way (`lessons.run_signals`), so the dislike taught the runs
  after it nothing;
- the notes that had steered the disliked run were handed to the next run of the same task again.

The functions written for this with item 586 (`propose_lesson`, `propose_rewrite`) have no caller. The owner agreed
to the fix proposed in the chat: the dislike becomes a lesson, and what steered the disliked run is shown.

**The change.**
- `store`: `followed_reactions(run)`, the reactions that stand whose follow-up a run is.
- `agent/lessons.py`:
  - `run_signals` takes the reactions a run follows up. A 👎 or a 🔁 is a signal: the owner disliked the earlier
    run's work, and what this run did otherwise is the lesson, to be done that way from the start next time.
  - The rest of the pipeline is unchanged: the review model drafts, the gate filters, `auto` vets and saves,
    `propose` waits. The nightly reflection and the harness read the same signals.
  - A chat run, which drew no lesson, is asked too when it follows up a 👎 or 🔁 (`may_learn_from_dislike`, and
    `LessonCase.only_if_disliked`, which `learn` checks against the store). Most of the owner's runs are chats; the
    review of the first push pointed out that the follow-up there would have taught nothing.
- `disliked_of(run)` gives the disliked run, the reaction, and up to ten of the notes it was handed that are still
  kept (`memory_uses`), the most used first. `GET /runs/{id}` gives it as `disliked`.
- `views/run.js` and `run.css`:
  - the run's lessons card lists those notes under a quiet line, each with Forget, which puts it in the trash;
  - a forgotten note stays in the card as Forgotten;
  - the card shows when no lesson was drawn too.
- Left for later:
  - a learned skill the disliked run used, rewritten from the correction (`propose_rewrite`);
  - notes handed to several disliked runs, flagged on the Memory page.
- `docs/autonomy.md` (lessons) and `docs/runs.md` (reactions) say so.

**Checked.**
- `tests/unit/test_disliked_lessons.py`, new:
  - a 👎 and a 🔁 are a signal, once each, and a chat of its own that ended done may learn from them only;
  - a ❓ and no reaction are none;
  - in the store, the follow-up of a 👎 has the signal and names the note the disliked run was handed, but not one in
    the trash;
  - another run of the chat has neither;
  - taken back, the reaction gives neither.
- `tests/smoke/test_lessons_card.py`:
  - the follow-up's page, at 1280 dark and 390 light, shows the card with "1 to look at" and the note;
  - Forget puts the note in the trash, and the card says Forgotten.
