### 1254. OpenRouter's 402 for credits held by requests still running is retried, not "out of credits"

**Status: done (2026-11-20).** Dot's record: ten runs failed with OpenRouter's HTTP 402 "This request would exceed your
available credits given your current in-flight requests. Retry after in-flight requests settle, or add credits."
OpenRouter prices a request at the longest answer it allows (the model's own limit when Dot names none), and holds that
price for every request still running, so calls made side by side (helpers, work orders, a run beside a schedule) are
refused while the balance pays for each of them alone. The classifier read every 402 that speaks of credits as a spent
balance: a `ProviderCreditError`, not retried, the model paused as "out of credits", and the owner told that a payment
was needed. The provider's own words say the refusal passes when the other requests end.

Now `classify_openrouter` reads a 402 that names "in-flight requests" as a `ProviderRateLimitError` (status 402 kept),
and `is_retryable_provider_error` retries a rate limit whatever its status, so the connector waits and asks again as
it does after a 429; when it still comes back the model is paused as "rate limited", which moves the run to a standby
model and tells the owner nothing about money. The page reads a run's last words by their status, so a run this 402
still ends reads in the sidebar and on the chat's card as a limit reached (`errors.js`, `serviceCause`, by the same
words the classifier reads), not as a balance to top up. The 402 of a request the balance does not pay for alone ("requires more
credits", seen 2026-10-19) is unchanged: out of credits, its `max_tokens` lowered once when the
message names what the credits pay for.

Not done: naming a `max_tokens` on every call so that fewer credits are held. Which length to name is a choice of each
call's caller, and the retry already settles what the record shows.

Checked: `tests/unit/test_provider_errors.py` and `tests/js/errors.test.js` (both new tests fail without the change),
the unit and smoke tests of the providers' retries and classifiers, ruff, mypy, `npm run check`.
