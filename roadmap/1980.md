### 1980. A stopped run keeps the words it had streamed, with a quiet "Stopped" note under them

**Status: done (2026-11-27).** Stopping a run replaced the words it had streamed with "The run was stopped.", so what the owner had read was gone (2026-11-26 review, C-ux item 5).

What was built: when the root run ends stopped, the message it was still writing stays as the answer, with a quiet "Stopped" note (`.answer-stopped-note`) in place of the daemon's own sentence, and the bubble that held the words goes. The emergency stop's result and the results of a run cut off when the daemon shut down or its `dotx` command ended are the daemon's English sentences too: they get the same note (`isStoppedResult`). A run stopped before it wrote anything says so as before. The words are the page's own, kept while it is open; they are not stored, so a page that reads the run again later shows the note without them.

Checked: `tests/smoke/test_stopped_run_text.py` (a model that streams and waits to be stopped; the owner presses Stop; the words stay under a "Stopped" note, in English and Turkish; and the same after an emergency stop, in Turkish).
