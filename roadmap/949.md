### 949. A plugin's proposal says what its skills need that it does not bring

**Status: done (2026-11-03).** **Found** by a run the owner asked about their new plugins: Desktop Commander's six
skills loaded, but all of them call the tools of its MCP server (`start_process`, `edit_block`), which a plugin of the
gallery does not install (its skills alone are), so they only describe what Dot cannot do through them. The owner
installed it not knowing.

**Built.** The scout's review (`plugins/scout_review.py`) answers `needs` too: what the skills call for that the plugin
does not bring and the owner must connect or install first (an MCP server, a program a Mac lacks, an account), in the
owner's language, empty for nothing. Customize › Plugins shows it on the proposal under **Needs:**.

**Checked.** `tests/unit/test_scout_review.py`: the review is asked for it, reads it and cuts it to its length; a
verdict without it needs nothing.
