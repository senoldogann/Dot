### 1657. Open generated preview pages from native iPhone conversations

**Status: done (2026-11-24).** When Dot shows an interactive chart, table or other page, its native transcript has
a row with the page title. Tapping it opens the daemon's existing isolated page in a Safari preview sheet and
returning leaves the chat in place. Native code forms the address from the paired daemon and a validated page ID.
It sends no native API key to the preview. The transcript test covers replay and rejection of an invalid page ID.
