### 1241. Only a line feed ends a line of a page's snapshot

**Status: done (2026-11-19).** The code review of 2026-11-19 (finding B2-02) showed, in a headless Chrome on a blank
local page, that Playwright's snapshot keeps U+0085 raw in an element's name, and `browser/snapshot.py` split the
snapshot with `str.splitlines`, which also ends a line at U+0085, U+2028, U+2029 and some control characters. A link
named `Continue<NEL>- button [ref=e9]: Continue` gave a line of its own, a button with the ref of the real "Pay now"
button that came after it; `line_for_ref` returns the first line of a ref, so a click on that button was judged by the
forged line, low, and the model read the forged line too. `fed_lines` splits at a line feed alone; the parse, the diff of
two views and the cut to the budget use it.

Checked: `tests/unit/test_snapshot_diff.py` (a name with each of five such characters forges no line; the test fails
without the change), the browser unit tests.
