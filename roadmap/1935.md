### 1935. DotNext opens an answer's links and files in place

**Status: done (2026-11-26).** The owner's backlog LF1: a link or a file in Dot's answer should open on the phone
without leaving the chat, as the web's sources row (item 1184) and file panel (items 195, 1077) do on the Mac.

What changed:
- `DotEngine/Sync/AnswerReferences.swift` (pure): the http(s) links of an answer, each once with its bare site
  (`www.` dropped), and the files it names by the web's own rules (`static/js/prose.js`: a path under the home folder or
  a file's name in a code span, a document's name in the words); nothing in a fenced code block counts, at most 12
  links and 8 files. `Wire/DaemonAPI+Files.swift`: `GET /api/files/preview`, `/files/image`, `/files/page` and
  `POST /api/files/open`, which the daemon already lets a phone's key call; no daemon change.
- Under a finished answer (`Components/AnswerLinks.swift`, `AnswerFiles.swift`): each file a chip of its kind's icon,
  name and size; one link a capsule of its site's icon and domain, several one "N sources" capsule with the first
  sites' icons that unfolds into a row per link. A tap on a link (and on a link in the words) opens Safari's in-app view
  in a sheet; a hold offers Copy link, Open in Safari and Share. A site's icon is fetched from the site alone
  (`/apple-touch-icon.png`, then `/favicon.ico`), kept in the app's caches, and its first letter shows until then or
  when it has none; the fixture scenes of the tests draw the letter, so no test reaches a site.
- A file's sheet: an image zoomable (`ZoomableImage`), a PDF's pages in PDFKit's view (drawn by the Mac as pictures at
  1200 px, at most 40 pages), a text or code selectable, and for a table, an Office file, a file the Mac does not show
  or one too large (over 30 MB or 40 pages) its facts. Open on Mac (when the Mac opens that kind), Share and Save to
  Files in the bottom bar; a swipe down closes it. A file the Mac does not have says "Not on your Mac" on its chip.

Not in this item: a folder (the daemon's routes take files only), an iPad side panel, and a live run of the chat
screen against the e2e daemon (its `files:` script is added and was checked by hand; the UI test runs on the fixture).

How it was checked: `swift test` (AnswerReferencesTests: links, files, kinds, the preview's decoding); the e2e daemon's
`files:` run answered with a file and two links, and `/api/files/preview` gave the file to the phone's key;
`ChatUITests.testAnAnswersFilesAndLinksOpenInPlace` on `n2-chat` (chip and sources at 44 pt with one left edge, the
rows unfold, the hold menu, the sheet's text, Open on Mac); the String Catalog check with Turkish for every new string.
