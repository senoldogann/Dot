### 711. The plugin scout looks every night, and the brief says what waits

**Status: done (2026-10-27).** The nightly part of the living gallery (item 710): the scheduler starts the scout at
`[scout] time` (03:30 by default, `"off"` stops it) as it starts the reflection: once its time has passed since the last
night, never twice at once, a night the daemon slept through caught up once; the emergency stop cancels one under way
and keeps the next from starting, and one cut off stores nothing. `plugins/scout_service.py` gives it the owner's recent
goals (runs started on Dot's pages or by iMessage), GitHub's token of Connectors when there is one, the review model,
and one night at a time (the owner's Look now waits for the scheduler's). Only the daemon's scheduler may start a night
(`Scheduler(..., scout=True)`): the first gate of this change found a test that ticks a scheduler with its own clock
starting a real night (GitHub, the review model and a read of the GitHub token from the Keychain), which a test must
never do; a scheduler made anywhere else now never starts one. `[scout]` bounds a night: 25 plugins, 20 updates, 30
minutes, 120 s a review. The morning brief says how many proposals wait, only the numbers (a plugin's name is a
stranger's words, which the brief does not quote).

**The review of the first push:** a night stored the state it began with, over the Install or Skip the owner made while
it looked; it now lays what it found over the state as it is when it ends (`merged`), under the lock the owner's
decisions are written under (`state_lock`). A night is refused while the emergency stop is engaged, and one engaged
during it ends it with nothing stored (logged `scout_stopped`, not as a failure).

**The review of the fourth push:** the brief counted only the proposals marked proposed, while the page counts an
install a daemon that died left off as waiting too: the brief counts with the page's own `waiting` now
(`test_morning_brief.py`, which fails on the code before).

**The review of the seventh push:** at the scout's time the scheduler queued a second whole night behind a Look now the
owner had started a minute before: a look under way is now that night's look (`test_scheduler.py`, which fails on the
code before).

**The review of the tenth push:** `docs/safety.md`, the contract, did not say that the emergency stop holds the nightly
look; it says so with the rest it holds.

**The review of the thirteenth push:** the scheduler read the whole scout state at each tick before it knew whether a
night was due: it checks the time since its last attempt first.

**Checked.** `test_scheduler.py`: a scheduler made without the daemon's word starts no night; the night starts at its
time and not before, once while it runs, never when off, and the stop cancels it. `test_morning_brief.py`: two proposals
waiting are told as numbers, a refused one is not, and a name that tries to close the brief's fence is not in it.
