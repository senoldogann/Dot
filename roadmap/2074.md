### 2074. A bot's Model page is the model picker: Main model on top, the providers as groups that fold, a search

**Status: done (2026-11-28).** The owner's shot of 2026-11-28: *Configure the bot › Model* was one long flat list, a
section per provider holding every model with its raw reference under it (`openai:gpt-4.1-2025-04-14`).

- The iPhone app's `AgentModelPage` draws the app's one model catalog (`ModelCatalog`, as the chat's settings and
  Settings › Models): **Main model** on top and ticked while the bot follows it, the recent models, the providers as
  groups that fold (all but the chosen model's folded, a count when folded, a tap opens or folds), each model with its
  provider's mark, "Default" under the daemon's main and a ✓ on the chosen one, and the search with its filter at the
  foot.
- The web's bot editor replaces its model `<select>` with the chat settings' list (`modelSections`): the **Main model
  (…)** row on top, the favourites, a section per provider that folds (the chosen model's open), a tick on the chosen one
  and a search; a model the daemon no longer offers is kept and said so under the search.
- Which model a run takes is not changed (that is another fix of the same day): the page writes the bot's own choice.

How it was checked: the DotNext build on GitHub; `BotsLiveUITests` gains the Model page (Main model chosen, the groups,
the search) for `scripts/e2e_bots.sh`; `tests/smoke/test_agents.py` (the editor's list, a model no longer offered kept);
`npm run check`.
