### 1930. DotNext attaches videos and files from the composer

**Status: done (2026-11-26).** The + menu in new and existing chats opens the photo library for images and videos,
the camera for photos or video, and Files for documents and audio. Video chips have a thumbnail and duration. File
chips show the type, name and size. The outbox keeps the bytes, names and media types through an offline restart.
It shows upload progress and lets the owner cancel and retry without sending the message.

DotNext exports video as 720p MP4 with sound. A 1920×1080, 30 fps test pattern with a tone exported on macOS using
the same AVFoundation preset. The 30-second result was 25,980,014 bytes and the 60-second result was 53,782,498 bytes.
Both retained an AAC track. Keep the HTTP upload cap at 20 MiB because the daemon reads the whole base64 JSON request
into memory. An oversized video shows its duration and size and can be shortened in the iPhone's system trimmer.

The web composer already accepts video through + and drag-and-drop. A browser test sends both to a run. A separate
smoke test uploads a video and runs `watch_video` with a scripted provider, with no model call. DotEngine tests
cover offline persistence, wire payloads, upload cancellation and retry. The iPhone UI test adds its bundled clip
from +, reads the duration and removes it at the accessibility text size. Swift build, the Turkish catalog check,
Python lint and types, and `npm run check` passed.
