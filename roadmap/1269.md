### 1269. A chat's links are pills, and its internal events wait in the details

**Status: done (2026-11-20).** An answer's links were the address, underlined, and a compaction was a line of token
counts across the conversation, with a system message or a hidden wake beside it when one was drawn. The reader had to
parse the address, and the record of the run sat in the thread.

A link in a message is now a pill: the site's own icon and a short label (the words of the link, or `#1001` for a
GitHub pull request or issue, or the site). It opens in a new window, which the desktop shell hands to the browser.
The icon is fetched from `https://<host>/favicon.ico` by the daemon, cached, and served from this Mac. A host that is
not a public name is refused, and the address the reader clicked is not sent to a favicon service. Offline, or when
the site has no icon, the pill keeps the link icon.

A compaction says "Earlier messages were condensed". Its sizes stay in the page and show with **Show internal
events**, which stands in a chat that holds a compaction, of the run being drawn or of an earlier turn (a rule of the
style sheet: the page holds such a record). Nothing of what a model is given changes.

The pre-push review of the whole change, once another session took it over, found: the rule hid system messages,
hidden wakes and plumbing tool calls that no event of Dot's is (only `compacted` is real, so the rule and the docs say
that alone); the favicon request missing from what leaves this Mac (`docs/safety.md`); a failed fetch dropped and kept
as "no icon" for ten minutes, and in the page for its life (now logged with its reason, answered 502 and not kept, and
asked again on the next drawing; a site's server error too); the redirects the fetch follows, which the safety page now
names; the toggle never shown for a compaction of an earlier turn.

Checked: `tests/js/chatview.test.js` (the pills and the hidden events; it failed before the change), `tests/unit/test_favicons.py`,
`npm run check`, and the quiet-compaction smoke test updated for the short line.
