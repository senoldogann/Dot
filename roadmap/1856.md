### 1856. What a run and a task cost in dollars, estimated from a public price list, beside their tokens

**Status: done (2026-11-25).** Taken from the study of Hermes Agent (`reports/refs-2026-11-25/hermes-agent.md`, item 3:
its `agent/usage_pricing.py`); the owner approved it on 2026-11-25. Dot showed tokens only and said so
(`docs/limits.md`: "keeps no price for a model, so none of this shows money"); money is the owners' second complaint in
the market study.

What must hold: an estimate, never a guess: a model with no price makes the estimate "unknown", not smaller; a
subscription (the Claude plan, OpenCode Go, Antigravity, Ollama's cloud) adds no dollars and says so; the caps stay in
tokens, unchanged; no test reaches models.dev.

What was built:
- `llm/pricing.py` (pure): reads models.dev's `api.json` for Anthropic, OpenAI, Google, OpenRouter and OpenCode Zen;
  says how a `provider:model` is paid for (priced, plan, local, unknown); prices tokens with cache reads and writes (a
  missing cache price billed as input) and context tiers, call by call.
- `llm/price_list.py` (the adapter): `prices.json` in Dot's home, a conditional fetch with the ETag, three tries with a
  doubling wait and a warning each, then the error raised; the daemon's `keep_prices` loop fetches at start and daily,
  logs a failure and tries again an hour later. `DOT_PRICES_URL` sets the address; empty fetches nothing, as
  `tests/smoke/conftest.py` sets it.
- `store/costs.py`: the tokens of runs by the model of each `model_call` event and by tier bucket, and what a run counts
  beyond its calls on its own model (OpenCode's agent, the run ledger of deleted chats).
- The API: `cost` of each day and each of `top_runs` in `GET /api/usage`; `cost` (the run's own) and
  `budget.spent_cost` (with its helpers) in `GET /runs/{id}/stats`. Additive fields, which the phone reads as they come.
- The web UI: the Cost card's **Cost** line, the helpers' line beside the cap, each day's and the week's line and each
  costliest task in Settings › Models › Usage ("~$0.42", "+ plan", "on a plan", "cost unknown").

Not done: the Caps section's today line, a campaign's and the activity rows' usage stay in tokens; OpenRouter's own
`usage.cost` is not read (its list price is used); `ios/` is not changed.

Checked: `tests/unit/test_pricing.py`, `tests/smoke/test_cost_estimate.py` (a local price list: ETag, 304, three tries;
a run with a tier, a standby model, a helper without calls, an unpriced model), `tests/js/usagewords.test.js`, the usage
and statistics tests, ruff, mypy, `npm run check`, and `tests/smoke/test_check_and_cost_screens.py` (a browser test,
wide and 390 px: the schedule's check, a check watcher, the day's dollars and the Cost card, every model call on the
scripted provider). A first look at these screens was a script run outside pytest, whose run page asked the default
fast model for a recap through the local Ollama server on the owner's account (answered 429): the browser test
replaces it, under the tests' guard of the owner's keys and with every model role scripted.
