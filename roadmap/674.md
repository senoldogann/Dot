### 674. A long chat no longer freezes Dot.app

**Status: done (2026-10-26).** The owner: in Dot.app, a big chat opened late and froze while it was opened, scrolled
up and while Dot worked in it. Chrome showed none of it; Dot.app draws in WebKit.

**What was measured** (WebKit 26.5 at 2x, the owner's own chats read from the live daemon, `/js` and `/css` served
from the branch): a chat of 17 tasks, one at work, held 28,000 elements; changing the page's font size once took
73-138 ms, and a run's step froze the page for 500-900 ms. Hiding the history alone took that to 12 ms, hiding only what
its closed details hold to 14 ms: WebKit styles the content of a closed `<details>` again at every change of the page,
and a long chat folds tens of thousands of elements (every call of every earlier turn, the rows of each folded group).
Two smaller costs came with a run at work: each frame of a watched browser was decoded with `Uint8Array.from` and a
mapping function (4.3 ms a 120 KB frame against 0.2 ms for a loop, in Node), and the Changes section drew every line of
every diff of the chat (7,007 lines, 411 KB, in that chat) again after each file a run wrote.

**The change.**

- `app.css`: `details:not([open]) > :not(summary) { display: none; }`. What a closed box shows does not change;
  opened, a body still fades in (`@starting-style` applies from `display: none`). Chrome's find in the page (⌘F) no longer
  opens a folded box to show a match inside it; WebKit never did, and a folded box's text is also on the run's page.
- `api.js` `frameUrl(base64)` decodes a screencast frame with a loop; Dot's computer and the teach panel use it.
- `changes.js`: a file's diff lines are drawn when it is first opened, and the section is not drawn again when what
  it reads has not changed.

**Measured after,** same chats, same engine: a relayout 138 → 15 ms (the chat at work) and 54 → 20 ms (a chat of 78
tasks); the longest freeze while a run worked 896 → 206 ms; the freeze while the chat opened 929 → 607 ms.

**Checked.** `test_flow_fold.py` holds that a folded group's body is `display: none`; `test_changes_panel.py` that a
closed file draws no diff line; `test_takeover.py` decodes a frame shown in Dot's computer. `npm run check`.

**Not done.** The rows of a folded group are still made when the turn is drawn (the chat at work still holds 22,000
elements); drawing them when the group is first opened would cut the opening further.
