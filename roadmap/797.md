### 797. The user's secret is theirs to hand over, a left question tells them, and a run ends by itself

**Status: done (2026-10-28).** **Asked** by the owner: "Bu yanlışları ve eksikleri düzelt o halde ve testlerle
kanıtlayarak temizce pr açıp merge et maine bittiğinde." The three gaps were the ones an audit of the system put
first: a password the owner gave was refused outside `yolo` by the prompt and the browser while a page's own secret
had to stay refused; a question left on a chat nobody was watching told nobody; and a run had no default time or
token ceiling.

- **A secret the user gave.** `ToolContext.user_text` reads the run's instructions as they stand (the goal and every
  instruction since), and `_secret_field_check` lets the text into a secret field when that text is in them. The
  check now receives the text the step would write: `fill`, `type` and `insert` carry it through `_into_editor`, a
  `select` carries its value; a key pressed with `press` carries none, so a code cannot go in one character at a
  time. A page or a tool's output is never in `user_text`, so a secret found there is still refused. The prompt
  outside `yolo` says the same, and `docs/safety.md` names the rule.
- **A left question tells the user.** When `ask_user` leaves a question (a run that chooses, or one nobody watches),
  it sends a macOS notification with the question; a notification that fails is logged and does not fail the
  question. A question asked with `wait` in a run the user watches is not notified twice.
- **A run has a default ceiling.** `run_max_minutes = 120` and `run_max_tokens = 10_000_000` in `defaults.toml`;
  either at 0 turns the bound off. The run is told at the first step past it to finish with what it reached, as
  before; the docs on autonomy, limits and runs say so.
- **Measured.** Unit: `test_ask_user_notify` 1, `test_limits` 6, `test_run_modes` 40, `test_lean_prompt` 7; full
  unit 6,268 passed with the three pre-existing environment failures (plugin gallery, two service-install tests).
  Smoke: `test_secret_fields` 12 (a code the user gave is typed and the form submits; the same code one key at a time
  is refused; a code found on the page is refused), `test_left_questions` 15, `test_run_limits` 6, `test_browser` 50
  passed with the pre-existing late-tab failure. See `docs/safety.md`, `docs/autonomy.md`, `docs/limits.md`,
  `docs/runs.md`.
