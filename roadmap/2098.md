### 2098. A file's preview on the iPhone reads by its format: Markdown formatted, tables as grids, the end clear of the controls

**Status: done (2026-11-28).** The owner's shot of 2026-11-28: `C8.out.md` opened in DotNext's file preview as raw
text (`## Rapor`, `**87 not**`, backticks, a pipe table with its `|---|---|---|` row), and its last lines lay under
the floating Open on Mac button and the Share and Save pill.

What changed:
- DotEngine: the Mac's `table` preview (a CSV or TSV file) is decoded into `FileTable` (its rows, the header first,
  and where reading stopped) instead of a kind shown by its facts; `fileTextFormat` reads a text file by its name with
  item 2017's rules (`changeFormat`): Markdown, JSON, code by language, or plain text; `textPieces`,
  `fileTableColumnCharacters` and `fileTableCellIsNumber` are pure. A table keeps no file on the phone, so it offers no
  Share or Save to Files: the rows read are not the file (cut at the cells the Mac reads, its delimiter and empty rows
  not kept).
- DotNext: the chat's Markdown renderer is one view, `MarkdownBlockView` (taken out of `AnswerView`); a Markdown file
  is `MarkdownDocument`, its blocks drawn by it in a `LazyVStack`, a table of more than 40 rows showing its first 40
  with "Show all N rows" opening it whole on the grid; Formatted/Source as in the Changes sheet, the source in item
  2017's `CodeLinesView`; JSON laid out and code coloured in that view; plain text in pieces of 60 lines; a CSV or TSV
  file as `FileTableView`: the header pinned, rows drawn as they come into sight, columns as wide as their widest
  cell among the first 200 rows (a longer cell wraps to 4 lines), numbers to the right, VoiceOver reading each row
  with its column names. The body is built off the main thread. Every scrolling page of the sheet ends 61.5 pt
  (`Metric.hit + Space.l`) above the bottom, clear of the floating controls. The Changes sheet's new Markdown file
  uses `MarkdownDocument` too, its blocks read once off the main thread.
- The fixture daemon answers `/api/files/preview` by the file's name (`FileFixture`), and the `n2-file` scene opens a
  file's preview at launch (`-DotNextFile <name>`).

How it was checked: DotEngine `AnswerReferencesTests` and `FileTextFormatTests` (`swift test`: the table decoded from
the Mac's cells, columns measured, numbers told, formats by name, pieces), an Xcode
`build-for-testing` and `check_strings.sh`; `FilePreviewUITests` (part of `ChatUITests`, so ios.yml's chat part runs it
on GitHub): the report formatted with no `##`, `**` or pipes left, its table a grid, its last line above Open on Mac,
Share and Save to Files at the end, its source a tap away, light and dark; a CSV as a grid; JSON laid out and a log as
text; and a 200 KB report and a 5,000-row CSV timed from their sheet to their content and over ten fast swipes.
