### 912. A thing is checked on itself before it is done, its note brought up to date after, and a rule of the owner's lets it go at once

**Status: done (2026-11-01).** **Asked** with item 910.

On the owner's Mac a run opened the Advectus assignment "not done yet", and found it had been handed in ten days
before; a run was given the Gistsmith checkout fix that the run before had already put live. And a thesis chapter the
owner had said never to touch was refused three times: the run had no `todo_drop` (its group was off), asked the owner
instead and ended failed, and the next try did the same.

- The opening of a thing (`_DO_OPENING`): check on the thing itself (the file, the page, the mail, the repository)
  that it is still to do; done already, say where and end; done now, bring the note or plan its why names up to date,
  in the copy the others are made from; a rule of the owner's: ask nothing, let it go with `todo_drop`.
- `loop.py`: a run of Dot's own initiative starts with the tool group `todos` on (`TODOS_GROUP`, `tools/groups.py`).
- `docs/proactive.md` says so.

**Checked.** The smoke test of item 910: the thing's run has `todos` on at its first step; without the change it had
only `core`.
