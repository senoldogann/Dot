### 1405. A skill Dot could not offer is listed on the Skills page, with its file and its reason

**Status: done (2026-11-24).** Found by the autonomy audit (finding 10). A plugin's `SKILL.md` that does not start with
the `---` line was a line in the log, 144 times in a day (`skill_skipped`, since item 1305 once per process) and nothing
the owner could read on the page that lists skills. Verified on `origin/main` before the change: `dotx doctor` and
`GET /api/doctor` already had a `skills` row that names each skill left out with its file and reason (`_skills_row`),
and `dotx skills list` a "Left out" block; the page had no route and no list, and its own header said Customize had none.

What changed: `GET /api/skills/left-out` reads the catalog as a run reads it and lists each skill it left out: the
`path`, the catalog's `reason`, the `source` of the folder it was found under (`home`, `config`, `plugin <name>`,
`learned`, `built-in`; `null` under none) and `shadowed` for one that is not wrong but only not offered because another
skill has its name; the ones whose file is wrong come first (`server/skills_left_out.py`). Settings › Skills puts a "Left
out" part at the foot of the tab the skill belongs on, Personal for the owner's folders and System for a plugin's, with
one plain sentence ("Dot could not read 1 skill, so no task is offered it. Mend the file and the next task reads it
again.") and a closed fold, "Skills Dot could not use", with a row each: the folder's name, the reason and the file's
path. Read apart from the skills, so that a failure of the route leaves them on the page. `dotx doctor` and
`dotx skills list` are unchanged: a test now holds that they say the same skill with the same file and reason.

Checked: `tests/unit/test_skills_left_out.py` (the audit's case, a plugin skill whose frontmatter is opened by a title,
beside a skill with none, a name taken twice and a missing folder: each listed with its source and reason, wrong files
first; the same file and reason on Doctor's row and in `dotx skills list`; a path is taken to the deepest folder that
holds it), `tests/js/skillleftout.test.js` (names, tabs, the sentence, the chip), `tests/smoke/test_skills_left_out.py`
(the route against a real home; the page in Chromium at 1280 and at 390 wide: the sentence, the closed fold, its rows on
the right tab only, nothing past the window's edge), `npm run check`.
Not done: a way to mend the file from the page (it names the file; the owner or a run edits it).
