### 673. A test of the channel router no longer depends on which run asks first

**Status: done (2026-10-26).** `test_a_run_typed_in_the_page_or_in_another_chat_tells_no_progress` of
`tests/smoke/test_channel_router.py` failed on two of four gate runs of pull requests #615 and #617 (`['In another chat.'] == ['Typed in the page.']`). It
starts a run in the channel's chat and one in another chat at once, and the scripted model hands its two replies out
in the order the runs ask: when the other chat's run asked first, the channel's run answered "In another chat.", which
the channel rightly sent.

**The change.** The test holds that what the channel sends is the channel's run's own answer, whichever reply it got,
and nothing of the other run's. Nothing of Dot changes.

**Checked.** The whole file, five times in a row (the test reads what the file's earlier tests set up, so it is
run with them, as the gate runs it).
