### 1356. "While you were away" is marked read for every device, not for a browser

**Status: done (2026-11-23).** Found by the autonomy audit (finding 6). The card's moment lived in one browser's
`localStorage` (`dot.away.read`): the Mac and the phone each replayed what the other had cleared, and a browser seen for the
first time marked itself read and showed nothing, so the first look from a new device could never answer "what did Dot do
while I was away". The chats' unread dots were already Dot's own record; this card was not.

What changed: Dot keeps the moment (`kv` row `away.read_at`): `GET /api/away/read` says it (`null` before any device
marked it) and `POST /api/away/read {until}` moves it on, never back and never past now. The card reads from it; the first
visit from any device sets it (from what the browser kept before, else now); Mark as read posts the card's `until` and
fails loudly (a toast) when Dot cannot be reached, where it used to clear a card it had not marked.

Checked: `tests/smoke/test_away.py` (the route test: no mark, set, never back, held at now, a negative `until` is a 422;
the card test now opens a second browser with no storage of the first, which sees the same news and none once the first
marks it, at 1280 and at 390 wide, light and dark), `npm run check`, `ruff`, `mypy`.
Not done: the card still lists schedules and campaigns only (the audit's finding 7).
