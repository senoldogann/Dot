### 830. A chat reads as people chatting: the steps fold away by default, and a run says what it does

**Status: done (2026-10-30).** **Asked** by the owner, with screenshots of another agent app ("ne kadar sade, sohbet,
tool çalıştırmaları vs. görünmüyor, sanki insanlar sohbet ediyor gibi; bu fotoğrafları da incele, öyle devam et"): its
agents say what they do in short lines ("on it — pulling that X post…", "found the feed path — checking …"), the
results come as files, pictures and cards, and no step, command or tool shows. The first part of the plan the owner
chose the same night (an agent-first Dot, in stages: group chats, a plain sidebar, a Trader agent instead of the trading
page, one way of learning, memory and rules that act).

What Dot had: Settings › Interface › *Work in a chat* (item 663) already folds every step and thought away under one
line of what the run does now (**What it is doing**), and a run's words with its calls are already its messages; but
**Every step** was the default, the prompt never asked a run to say what it does as it works, and the changes of the
memory and the agents' messages (item 733, folded) stood in the conversation either way.

- `layout.js`: **What it is doing** is the default until the owner chooses; a choice made stays.
- `prompt.py`, Communication: a run says what it does in one short line with its calls, as a colleague would in a chat,
  when it starts and when something changes, in plain words, with no tool's name and not a line per step.
- `run.css`: with **What it is doing**, "Saved to memory" and its like stand with the steps, out of the conversation
  until they are shown. `timeline.js`: there an agent's message is open, as people's are; with **Every step** it is
  folded as item 733 made it.

**Checked.** `tests/smoke/test_work_status.py`: by default the steps are hidden and the line offers them.
`tests/smoke/test_agent_said.py`: an agent's message folded with every step, open with what the run is doing. The tests
that read the steps of a run choose **Every step** (`test_chat_calm`, `test_dot_reaction_page`, `test_flow_fold`,
`test_phone_rows`, `test_run_chrome`, `test_thinking_blocks`, `test_thread_turns`, `test_why_it_ran`, `test_yolo_line`,
`test_memory_line`, `test_conversation_lane`), once each page or context they make.
`tests/smoke/test_context_budget.py`: the system prompt's ceiling raised by 100 for the line (7,231 measured).
