### 499. Choose tools works for a server that signs in

**Status: done (2026-10-21).** Reported by the owner: Linear (76 tools) and Postman (233) signed in on Connect apps and
were left out for offering more than 30 tools, as they should be, but **Choose tools** then failed with "the MCP
server refused the connection". Every server that signs in and offers more than 30 tools did the same.

**Cause.** A try learns that a server signs in only from the sign-in it gives (`signed_in`), and wrote that
(`oauth = true`) into the config it keeps only once the server answered with tools it could use. A try left out for
too many tools kept the config without it, so `GET /api/mcp/servers/{name}/offered` and `PUT .../allow` connected
without the kept sign-in, and the server answered 401.

**As built.** A try that fails after signing in keeps `oauth = true` in its config (`server/routes_mcp.keep`), so Choose
tools lists the tools and connects the chosen with the kept sign-in, and the server is kept with it.

**Checked.** `tests/smoke/test_mcp_sign_in.py` gains a server that is its own authorization server and offers 31
tools: added, signed in to, left out with Choose tools, then listed, connected with one tool that answers, and kept
with `oauth = true` and its allow list, with one sign-in. It failed before the change (`signs_in` was false).
