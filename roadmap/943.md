### 943. The repair night trusts no push without the hook's mark, reopens a fix only once it runs, and restarts safely

**Status: done (2026-11-02).** **Found** by independent reviews of the latest work and of the scheduler (2026-11-02):
- A push that git took was read as a passed review: a session that pushed its own branch first (its way to GitHub is a
  default, not a boundary) left Dot's push nothing to send, the hook reviewed nothing, and with `merge = "on_pass"` the
  pull request was merged, pulled and restarted with no review.
- A fixed problem reopened on what the code before the fix logged (while the merge waited for a restart), and one let
  go reopened at its next sighting; each was handed to a second session for nothing.
- A problem's title was masked after its numbers were written `<n>`, when a secret with digits is no longer known.
- The restart a merge asks for ran `python -m dotagent` in the home folder without `-P`: a `~/dotagent/__main__.py` a
  sandboxed run left there would run instead of Dot, outside the sandbox.
- A restart that gave up (a run waited for the owner two hours) left the daemon on the code before the merge, told to
  nobody, and the nights after went on in it.

**Built.**
- `repair/github.py` `push_branch`: the branch on GitHub must stand where Dot left it before each push (nowhere before
  its first: a session that pushed a commit of its own there would have the hook review only what came after, the
  pre-push review), and a push that went through is a passed review only with the hook's mark of that commit
  (`.git/claude-review/<sha>.pass`); else `UnreviewedPush`, and the night ends the session as the owner's.
- `repair/problems.py`: a problem keeps when it was settled (`settled_at`); a fixed one reopens only when seen by a
  process that began after it was fixed (`fixed_again`, `repair_night`'s `running_since`), and one let go stays so.
- `repair/night.py`: sightings are masked before titles are made; a night whose process is older than its checkout's
  commit repairs nothing, asks for the restart again and tells the owner.
- `scheduler/runner.py` `restart_argv`: `python -P -m dotagent service restart --when-idle`.

**Checked.** `tests/smoke/test_repair_night.py`: a branch the session pushed itself, whole or in part, is never opened
nor merged; a night in a process older than its checkout asks for the restart and repairs nothing; the stand-in hooks
mark what they pass, as the real one does. `tests/unit/test_repair.py`: reopening (a fix running, a sighting before the
restart, one let go), and the restart's `-P`.
