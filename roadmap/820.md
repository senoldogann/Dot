### 820. The desktop's updater takes a zip without its Dependabot alert

**Status: done (2026-10-29).** Dependabot alert 24 (critical): `zip` up to 9.0.4 reads an archive whose two headers
disagree in a way another reader does not, so a file can be written outside where it is unpacked. Dot's desktop had
`zip` 4.6.1 by `tauri-plugin-updater` 2.14.0, which takes it on Windows only, so the Mac's app never built it; the
alert stayed open all the same, and an alert left open hides the next one.

- `tauri-plugin-updater` 2.14.1 (2026-10-28) takes `zip` 9: `cargo update -p tauri-plugin-updater` moved the lock to
  2.14.1 and `zip` 9.1.3. `Cargo.toml` asked for `"2"` already; nothing else moved but what `zip` 9 takes
  (`typed-path`, and `arbitrary` gone).

**Checked.** `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test` (89 tests) in
`desktop/src-tauri`.
