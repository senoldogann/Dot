### 1049. A question whose run is gone closes its card

**Status: done (2026-11-08).** Part of the owner's ask to make the implicit state machines explicit (item 1045).

`approval_requested` is always followed by `approval_decided` (the contract of `agent/approvals.py`), except where the
store expired the questions of runs that are gone: the daemon's start and a `dotx` command found dead
(`expire_pending_approvals`). Those wrote the record `expired` and no event, so the timeline, which builds its cards from
the events, kept a card that could no longer be answered, also after a reload. The store now writes the
`approval_decided` event of each in the same transaction, and the manager tells the pages.
