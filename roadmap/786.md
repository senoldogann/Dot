### 786. The vault says where a login's password is, and an import says a second one

**Status: done (2026-10-28).** **Asked** by the owner, from the review of every module. On 2026-10-28 a run told the
owner "the vault has no passwords": it read the vault's records in Dot's database, whose `fields` are empty for every
login, and concluded none had one. A login's password is in the Mac's Keychain and its record never holds it; the
import writes each password to the Keychain before its record. Nothing told a run so but the description of
`browser_logins`. Now:

- **Said where it is.** `browser_logins` names each vault login with "its password in the Mac's Keychain", and the line
  of the prompt on logins says that a record shows no password for every login, that the vault is never judged to have
  none from a record, and that a password is never looked for in the Keychain or the database: a run fills it, and
  `browser_fill_login` says if one is missing.
- **A second password in an import.** A file with two rows of one site and username kept the first and counted the
  second "already in the vault, or twice in the file", even with another password, which was lost in silence (Chrome
  exports one row per address, so an old and a new password of one login can both be there). The second is counted
  under its own reason, "a second, different password for a login already in the file (the first is kept)".
- **A website saved in Unicode.** A login saved as `https://bücher.de` never filled on the page, which Chrome names
  `xn--bcher-kva.de`; a host is compared in its ASCII form.
- **A long note.** A cell past the csv module's own limit (128 KiB) refused the whole file as no CSV; the limit is
  raised for the read, and a note too long for the vault is left out as before.
- **1Password's newer export** (a Url and an OTPAuth column, as Safari's) was named Safari's in the report; it is known
  by the columns only 1Password writes.

**Checked.** `tests/unit/test_vault_import.py`, `tests/unit/test_vault.py` (the Unicode host), the vault items' and the
prompt's tests, `dotx eval check`.
