### 2042. Show task notifications and Live Activities in DotNext

**Status: implemented (2026-11-27).** DotNext registers for APNs after pairing and uses the existing device, push-to-start and fleet token routes.
Its own widget extension shows the live line and elapsed time of each active run and opens its chat. The daemon
sends the end as soon as the fleet has no active runs. The configured APNs topic selects the older app or DotNext.

DotNext sends task alerts for questions and approvals and for successful, failed and blocked ends. Drafts, routine
notices, campaign ends, briefs and watcher notices continue on their existing surfaces. The daemon logs when it
keeps one of those notices out of DotNext's task alerts.

DotEngine tests the wire and run links. A UI test opens the Live Activity link on a paired simulator against a
throwaway daemon. A fake APNs transport verifies progress and dismissal. Delivery on the owner's signed iPhone
remains unproven.
