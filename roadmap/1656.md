### 1656. Describe an appearance in chat and apply it across Dot clients

**Status: done (2026-11-24).** The owner wants to describe a look in chat, see it on their other open clients,
and ask for refinements. Quiet Forest is an example and a shortcut in Appearance settings.

The appearance tools read and replace a shared revision or undo a change. Each appearance describes two
sRGB palettes and optional artwork. The daemon checks text contrast and imports only a raster file from the
chat's authorized workspace as custom artwork. It stores at most the current and previous appearances, with
each image committed alongside its palette. Every device retains its own light or dark setting and returns to
its own selection when the shared appearance is cleared. Native iPhone keeps a copy for offline use.

The web and Tauri clients use the existing interface roles, while SwiftUI applies the shared palette in the
native conversation. The previous browser theme gallery and editor keep their local selection.

The browser integration test sends an appearance change through the model tool path and checks separate
light and dark windows, artwork, revision conflicts, reload, refinement and undo. The iPhone target is built
against the same daemon contract.
