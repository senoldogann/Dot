### 486. The browser tests in CI

**Status: done (2026-10-21).** The last of the CI items of the nine ideas from OpenBot (item 457 the release gate, item
487 zizmor). The browser tests ran on the developer's Mac only, so a change that broke a page reached main unseen: item
488 found two such breaks, and this item three more. **As built.** `gate.yml` has a `browser` job beside the gate's own,
so that a red one hides nothing of the gate's: on macOS, with Playwright's headless shell and WebKit installed (Google
Chrome is on the runner's image), it runs the core of the browser tests in two parts, the pages and the phone (a
matrix), each on a runner of its own and one worker (a runner has three cores and a worker drives a Chrome and a daemon;
the trials at three and at two workers timed pages out): the files whose names start `test_browser_` and `test_phone_`
(a new one joins by its name), `test_secret_fields.py`, `test_page_guards.py` and `test_face.py`. `browser.yml` runs
every browser test every night and when asked (`gh workflow run browser.yml --ref <branch>`, once it is on main), on one
worker for hours, blocking nothing; the release calls the gate, so it runs the core too before it publishes. Three tests
that failed on main: `test_first_chat.py` pressed Return to send on a phone, which breaks the line there since item 440
(it taps the send button); the Options menu of `test_composer.py` measured 609 px under a cap of 600 px at 1280×900 (the
cap is 640 px, still within the room above); and the browser test of `test_schedule_memory.py` read a schedule that a
test it does not run with makes (it makes the firings itself when they are not there). Six more failed in a full local
run at three workers on a busy Mac and pass alone (page guards, the composer's bar, the queue, the model menu, Settings
› Phone, the role models): the nightly run shows whether they hold on a runner. Three browser tests (two phone files and
the tour) saved a note with its embedding, which asked the local Ollama server; they turn embeddings off, as the tests
beside them do. Docs: development.md, CONTRIBUTING.md.
