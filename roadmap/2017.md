### 2017. A change reads by its format, on the phone and the web; This chat's sections start folded

**Status: done (2026-11-27).** The owner's shots of 2026-11-27: the iPhone's This chat sheet was all Changes, and a new
`.py` file opened as a raw unified diff in the body font, soft-wrapped, a `+` on every line, no colour.

What changed:
- DotEngine `Sync/ChangeView.swift` and the web's `diffview.js` read a change with one set of rules: the diff into rows
  with both line numbers, a new file (created, or a hunk that adds every line to nothing) as the file, the format from
  the name (code by language, Markdown, JSON, image, PDF), JSON laid out in its own key order, and a small scanner that
  colours keywords, strings, comments, numbers, keys and headings for Python, JavaScript, TypeScript, Swift, JSON,
  TOML, YAML, shell, Markdown, HTML/XML, CSS, Rust and Go; a comment or a long string runs on over lines. No
  highlighter library on either side.
- DotNext: `ChangeSheet` replaces Quick Look of a `.diff` file: monospaced code at the code role's Dynamic Type size,
  never wrapped (scrolls both ways, every row as wide as the widest so a tint spans the view), numbers in the faint ink,
  tinted lines with their sign, hunks as a quiet band, a new Markdown file formatted with Formatted/Source, Copy; the
  lines are built off the main thread and drawn by a `LazyVStack`. An image or a PDF opens in `FilePreviewSheet`
  (LF1). This chat's sections (Messages, Run, Model, Recap, Cost, Helpers, Changes, Background) start folded, each
  header a 44 pt row with its count (lists) or its one fact (state, model, time, on/off); what is open is kept while the
  sheet is up and forgotten when it closes, as iOS's disclosure rows in a sheet are.
- Web: the Changes tab's rows (folded as before) open on the same view: sticky numbers, sign, tint, colours from
  `run.css` (light and dark), 400 rows at a time as they scroll into view; a new Markdown file formatted with
  Formatted/Source; an image or a PDF opens in the file panel. Words in both catalogues (en/tr).
- The daemon's `note` of a file without a diff is now decoded by DotEngine's `FileChange`.
- `translations_tr.py` gets the line of "Show cards" (item 1967 put it in the catalogue only, which stopped
  `apply_translations.py`).

How it was checked: DotEngine `ChangeViewTests` and `CodeLinesTests` (parsing, new file, format, JSON, colouring),
`tests/js/diffview.test.js` (the same cases), `tests/smoke/test_changes_panel.py` at 1440x900 light and 390x844 dark
(a changed `.py` as a diff with numbers and signs, a new `.py` numbered with no sign, a new `.md` formatted then its
source), and `InspectorSheetUITests` (sections folded with their count; a changed `.py`, a new `.py` and a new `.md`
in light and dark).
