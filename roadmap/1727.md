### 1727. DotNext's composer pickers: `/` commands and skills, `@` agents, teams, chats and accounts, `#` this chat's files

**Status: done (2026-11-24).** Wave N2 of the iPhone rewrite, the owner's order of the same day (PLAN.md §22, the
reference shots `ref-composer-commands.png`, `-mentions.png`, `-prs.png`).

What was built:
- A trigger at the start of a word opens one panel just above the composer: a quiet uppercase header per section and
  rows of icon · name · quiet description, filtered as the owner types; a tap puts the token in the text. `/` offers
  Dot's commands (/btw, /side, /loop, /plan, /model, /stop) then the skills (`GET /api/palette`); `@` the agents and
  teams first (`/api/agents`, `/api/teams`), then the other chats, then the accounts signed in; `#` the files this
  chat's runs changed. The capsule above stays; the panel is bounded so the composer stays above the keyboard.
- The composer does its commands itself: `/btw` and `/side` ask the run a side question (`POST /runs/{id}/btw`) and show
  the answer; `/loop 30m <message>` makes the chat's loop (`POST /runs/{id}/loop`) and sends the message; `/stop`
  stops the run; `/model` opens the model of this chat. `/plan` at the start asks for a plan first, and a picked skill or
  account goes with the message as the web's picks do (`skills`, `accounts`, `plan_first` of the queue's request),
  their tokens taken out of the words.
- Pure and tested in the engine (`Sync/Pickers.swift`): the trigger, the sections in their order and filter, the
  message's picks, the commands.
- A debug fixture's chat no longer reads or keeps a draft, so a scene draws the same each time.

Not done: `#` pull requests and memory notes (the daemon has no list of either for the phone); the web composer's `#`.

How it was checked: `swift test` (84 tests; each new test red once by a mutation; the one green showed a guard that
closed the panel while an account's address was typed, removed); the UI test of the `/` panel (rows, filter, a tap
putting `/loop` in the text), red once; the panel looked at on the simulator against the owner's shot, light and dark.
