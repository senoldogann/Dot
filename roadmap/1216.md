### 1216. An AppleScript failure says what its error number means and what to do next

**Status: done (2026-11-18).** In the old store 27.5 % of `apple_script` calls failed, with osascript's message in the
owner's macOS language and nothing the model could act on (`reports/agent-capabilities-2026-11-18.md`, CMP-P01).

- `desktop/script.py`: `osascript_error` reads the number osascript ends its message with, which is the same in every
  language, and `OSASCRIPT_ERRORS` says for fifteen numbers what it means and the next move (-1743: the owner allows
  Automation, do not retry; -600: start the application; -1728: the object does not exist; -1708: read the
  dictionary). The failure's message carries it; macOS's own words stay in the context.

Checked: `tests/unit/test_osascript_errors.py` (English and Turkish messages read the same; an unknown number or none
adds nothing; a real failing script on this Mac).
