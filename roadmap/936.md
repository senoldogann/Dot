### 936. An agent without the shell is told that no command runs in its run

**Status: done (2026-11-02).** **Measured** in the owner's record (2026-11-02): three runs of agents of the owner's
team (Sales Outbound, Product Performance, Release QA), whose tools are the web, the browser, the files, memory and the
team's but no `shell`, called `shell` for `curl` and lost the step: "Unknown tool 'shell'". Their system prompt said
otherwise: its ways of working ("Pick the fastest reliable channel: (1) shell, CLIs, scripts…", in the lean style
"Prefer the shell…") are the same for every run, whatever tools it has.

**Built.** `agent/prompt.py`: a run whose tools have neither `shell` nor `terminal_open` gets a section of its own,
right after the ways of working: no command runs in this run; the work they send to the shell is done with the tools
its list names (`web_fetch` or the browser for a page and its HTTP status, the file tools for a file), or said to need a
command; a tool the list does not name is never called. A run with the shell or a terminal reads the prompt it read.

**Checked.** `tests/unit/test_no_commands_prompt.py`: both styles tell a run without a shell or a terminal, after the
lines that name the shell, and neither tells one with `shell` or with the terminal. `tests/unit/test_lean_prompt.py`
compares the two styles of a run with the shell, as Dot's own runs are.
