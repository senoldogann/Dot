### 876. A template asks what its agent needs at Use, not in its first run

**Status: done (2026-10-31).** **Asked** by the owner, after the review of Dot against an agent-template article
(0xRafy, "GrokBot Templates"): a template that starts by asking a few setup questions gives a first run with a result,
where one that starts blank gives a first run that asks.

What Dot had: **Use template** made the agent in one click, and its instructions told the first run to ask the owner
what it needed (whom you sell to, which repository, which address): a run that ended on a question, or guessed.

- `agent/templates.py`: `AgentTemplate.questions` (three at most, `MOST_TEMPLATE_QUESTIONS`), set on the eleven
  templates whose first run had to ask; `with_answers(template, answers, known)` puts the answers after the
  instructions, each after its question, under "What the owner told you when making you", leaves a blank one out,
  and refuses an answer that holds a secret (a value Dot holds, or a key, token or password by its form).
- `server`: `POST /api/agent-templates/{id}/use` takes `TemplateUse` (`answers`, 500 characters each, three at most);
  no body makes the agent as before, so Use team and older clients are unchanged.
- `views/agents.js`: a template with questions opens **Set up <name>** (a field each, **Use template**, **Skip**,
  Cancel makes nothing); one without makes the agent in one click.
- `docs/agents-and-campaigns.md` says so.

**Checked.** `tests/unit/test_template_setup.py` (three at most; the answers' order and a blank one left out; a secret
refused), `tests/smoke/test_agent_design_pages.py::test_a_template_asks_its_questions_at_use_and_its_agent_starts_with_the_answers`
(desk and phone, in Chrome: the answers in the instructions, Cancel makes nothing, nothing sideways on a phone), and
the template tests skip the dialog where they used one click.
