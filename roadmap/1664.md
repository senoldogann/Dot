### 1664. Dot for iPhone: the code reviews stand apart from the owner's chats

(`source` `review`) as one of the owner's chats, among the working ones while it ran. The list keeps them apart now, as

(`ChatSections`, `ChatListView.reviewsSection`).

chats), written for the iOS helper to run; the files were parsed with `swiftc -parse`. Not built nor run: no xcodebuild
in this change, which another session holds.
