### 696. A chat closes the tabs it is done with, and only its own

**Status: done (2026-10-26).** The owner: a run should close the browser tabs it no longer uses, and only the ones it
opened, since other agents work at the same time.

**What was measured** (the owner's database, read-only, the 30 days to 2026-10-26): 102 `browser_new_tab` against 20
`browser_close_tab`; 27 % of the pages a browser tool showed were in a chat at its cap of four tabs, so the oldest tab
closed only when a fifth opened. No run's end closed a tab: they waited for `tab_idle_s` (30 minutes) after the last
use, a helper's chat as well, which no message continues.

**The change.** Tabs were already a chat's own (a helper starts a chat of its own; a tab the owner opens is in none),
so every rule works on one chat's list. `Tab.last_used` is set when a call ends with the tab current. The reaper
closes a chat's background tab unused for `[browser] background_tab_idle_s` (300 s; 0 keeps it), while the run works
too, skipping a chat in the middle of a step and the tab a task is taught in, and notes it on the current tab. The end
of a run (`RunManager._drive`, before the queue moves on) asks `BrowserPool.end_of_run`: a helper's chat (a run with a
parent) closes every tab, another every tab but its current one; nothing closes while a run of the chat is at work.
`browser_close_tab` without an index closes every tab of the chat but the current one.

**Checked.** `test_browser_tabs_tidy.py` (real headless Chrome): a background tab left unused closes and the current
one, and the fresh tabs of another chat at work, stay; a run's end keeps only the current tab and leaves another
chat's two; a helper's chat closes all, a chat at work keeps all; closing the others leaves the current tab and a tab
no chat opened. `test_run_end_tabs.py` (scripted model): a run's end asks for its chat with `helper=False`, its
delegated run's with `helper=True`, in a chat of its own.

A tab opened from one of the chat's tabs is the chat's (it was taken in before this item too), also when the owner
opened it that way, by a middle click in a tab of Dot's in their own Chrome: it now closes with the chat's background
tabs. The docs say so (the independent security review).

**Not done.** A tab Dot opens for a quiet read (web tools) is not a chat's and closes after the read, as before.
