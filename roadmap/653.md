### 653. Web-research 1.4.9 in Dot: Google's walls weighed by the path that met them

**Status: done (2026-10-25).** The dot-0b session released web-research 1.4.9 (tag v1.4.9, merge 2d9d5d1, on PyPI),
and this item pins it with the lock.

**What 1.4.9 brings (its author's account).**
- **A wall is weighed by the path that met it.** This closes the low finding of item 648's security review: a bot check
  that only headless Chrome or the HTTP path saw did not set `wall`. Making every weak check a wall would rest Google
  almost always, because headless Chrome is refused nearly every time, as on 1.4.7.
  - **A strong path's wall counts** (Camoufox, the minimised Chrome), unless another strong path read Google clean.
  - **A weak path's wall counts only when no strong path could be asked** and no browser read clean. The weak paths
    are an HTTP 429 or `/sorry/`, a headless Chrome CAPTCHA, and the hour headless Chrome stays off.
  - A Camoufox page that hung on `/sorry/` is a wall.
  - A path the Mac lacks raises `GoogleBackendMissing` rather than returning nothing.
- **A search no longer fails unasked.** When the first provider fails and every fallback is resting, the fallback
  nearest the end of its rest is asked once. Before, the search failed without a call.

**What changes for Dot.** Its dependencies, the `WEB_TOOLS_*` names Dot sets and the tools' arguments are those of
1.4.8.

**The change.**
- `pyproject.toml` pins `dotagent-web-research==1.4.9`.
- `uv.lock` moves that package alone. Its hashes match PyPI's, and its `requires_dist` is 1.4.8's.
- `docs/extending.md` gives the version and says that the resting fallback nearest its end is asked once.
  `docs/development.md` gives the version too.

**Checked.**
- Dot's web-research tests, unit and smoke, pass on the installed 1.4.9: 105.
- The installed package carries `GoogleBackendMissing`.
- **The independent security review** REVIEW.md asks for a dependency read the 1.4.8..1.4.9 diff by its code. It
  took 13 tool calls and found no blocker. The lock, `requires_dist` and the tool surface match 1.4.8. The wall
  weighing holds in the strong and weak cases, `GoogleBackendMissing` is caught by every caller, and nothing new runs
  outside the address guard (item 637). Two low notes went to web-research 1.4.10:
  - **L1.** The last resort runs once per angle (up to 4 in a search) and asks even a provider resting after a bot
    check. Each wall doubles that rest, up to the hour. `docs/extending.md` now says so.
  - **L2.** Camoufox takes a page empty of "captcha" and "unusual traffic" for clean, without the `enablejs` and
    `/sorry/` checks the Chrome paths have.
- The owner is asked before it merges.
