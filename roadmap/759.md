### 759. The desktop shell's Rust dependencies take the fixes that reach them

**Status: done (2026-10-27).** From the outside review of 2026-10-22 (Y2). `cargo audit` in `desktop/src-tauri` found ten
vulnerabilities: four crates fixed in a compatible release, and `zip`.

**The change.** `cargo update -p ctutils -p rustls -p rustls-webpki -p webpki-roots` (`Cargo.lock` only, no
`Cargo.toml`): ctutils 0.4.3 to 0.4.6 (RUSTSEC-2026-0385), rustls 0.23.45 to 0.23.46 (-0346 to -0349), rustls-webpki
0.103.15 to 0.103.16 (-0382), webpki-roots 1.0.9 to 1.0.11 (-0381).

**What is left.** `zip` 4.6.1 (RUSTSEC-2026-0367 to -0369, fixed from 9.0.0) comes from `tauri-plugin-updater` 2.14.0,
which asks for 4.x: it needs a release of the plugin, not a `cargo update`. `cargo tree` for the Mac's target does not
list it (only `--target all` does), so it is probably not built into the Mac app; that was not checked further. The
weekly Dependabot pull request and `audit.yml` will say when the plugin allows 9.x. The unmaintained crates
(`proc-macro-error`, `zbus_names`, `zvariant`, `zvariant_derive`) and the unsound-API notes (`glib` 0.18, `tokio`
1.53, RUSTSEC-2026-0386) are warnings with no fixed version.

**Checked.** `cargo audit` lists only `zip` among the vulnerabilities; `cargo fmt --check`, `cargo clippy --all-targets
-- -D warnings` and `cargo test` (88 passed) in `desktop/src-tauri`.
