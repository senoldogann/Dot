### 1910. DotNext's home opens the settings from an avatar icon, not from the owner's initials

**Status: done (2026-11-26).** The owner's request: the button at the top left of the bots home (item 1881) showed
the owner's initials ("SD"); it is now the `person.crop.circle` symbol.

- The button is a plain `Button(title, systemImage:)` in the toolbar, the same form as the "+" at the other end, so
  the system draws it in its glass with the same symbol weight, size and tint, centred, and a tap target of 44 pt.
  Its accessibility label stays "Settings" (Turkish "Ayarlar").
- The initials code path is gone: `initials(_:)`, the home's read of the owner's name (`GET /api/assistant`) and the
  banner it could raise. The owner's name is still read and edited on the settings sheet's General page.
- `BotsLiveUITests` measures the button: as large as the "+" button (the system glass, 44 pt), on its line, its symbol centred
  within 0.5 pt, its label "Settings".
